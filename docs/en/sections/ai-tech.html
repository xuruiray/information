Research and Governance: Long-Context Memory, Model Identity Verification, and Interpretability Tools

MEMENTO trains long-context LLM agents to decide what to retain in a fixed context window; the paper finds that off-the-shelf models such as GPT-5.5 and GLM-5.3 often write ineffective compaction notes. Another paper distills retrieved knowledge into parametric memory so LLMs can reuse it while aiming to cut storage and inference costs. Anthropic is developing FlashProve to let anyone check whether an AI response really came from the model it claims to be from; Circuit Oracle automates attribution-graph analysis through natural-language queries; and StateBench tests how language models track state changes over long documents.
