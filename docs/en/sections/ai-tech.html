Frontier Models: Falsifiable World Models and Elastic Recurrence

The frontier models subsection includes five papers. EvoBelief lets self-evolving LLM agents not only improve behavior but also evolve falsifiable world models of environment dynamics; an elastic latent recurrent language model reuses a shared block of layers so one checkpoint can trade inference compute for accuracy by changing loop count; Kairos explores a byte-level multimodal foundation model combining bidirectional gated-DeltaNet linear attention, sliding-window attention, block-wise attention-residual aggregation, and sparse mixture-of-experts; speculative decoding studies contextual correction of parallel drafts to improve verification of multiple tokens from a diffusion-based drafter; and CLEAT frames interactive intent alignment as clarification, studying how LLM agents use value-guided clarification to align with unstated user goals and constraints.

EvoBelief: Falsifiable World Models for Self-Improving LLM Agents arXiv 人工智能

The paper introduces EvoBelief, which evolves falsifiable world models for self-improving LLM agents to address incomplete or outdated beliefs about environment dynamics.

The paper proposes an elastic latent recurrent language model that reuses a shared block of layers, letting one checkpoint trade inference compute for accuracy by changing loop count.

Read more → Kairos: Toward a Byte-Level Foundation Model for Every Modality arXiv 机器学习

The paper introduces Kairos, a byte-level foundation model architecture combining bidirectional gated-DeltaNet linear attention, sliding-window attention, block-wise attention-residual aggregation, and sparse mixture-of-experts.

Read more → Contextual Correction of Parallel Drafts for Speculative Decoding arXiv 计算语言学

The paper studies speculative decoding acceleration and proposes contextual correction of parallel drafts from diffusion-based drafters to improve verification efficiency.

Read more → CLEAT: Learning Value-Guided Clarification for Interactive Agents arXiv 人工智能

The paper frames interactive intent alignment as clarification and studies how LLM agents use value-guided clarification to align actions with unstated user goals and constraints.

Research and Governance: Emergency Brakes, Agent Guardrails, and Benchmarks

The research and governance subsection includes five items. Microsoft CEO Satya Nadella wrote in a Saturday post that it is time to step back and assess AI's trust architecture, and TechCrunch reports he says AI models need an emergency brake; VEPA provides runtime guardrails for LLM agents operating on sensitive resources, making inspectable, reproducible, and deterministic allow-or-refuse decisions before potentially irreversible actions; GeopoliticalQA is a benchmark for grounded question answering over geopolitical and strategic intelligence reports; unsupervised multimodal reward modeling adds a linear head on an intermediate layer of a frozen Qwen3-VL backbone to score web captions above other text; and a position paper says explainable AI tools have largely failed to increase trust and analyzes structural misalignments in faithfulness metrics for feature importance.

Microsoft’s Satya Nadella says AI models need an ‘emergency brake’ TechCrunch AI

Microsoft CEO Satya Nadella wrote in a Saturday post that it is time to "step back and assess the trust architecture" of AI, and says models need an emergency brake.

Read more → VEPA: Verified Evolving Formal Policy for Lifelong LLM Agent Guardrails arXiv 人工智能

The paper introduces VEPA, a runtime guardrail for LLM agents operating on sensitive resources, making inspectable, reproducible, and deterministic allow-or-refuse decisions before potentially irreversible actions.

Read more → GeopoliticalQA: Benchmarking Retrieval and Generation over Intelligence Reports arXiv 计算语言学

The paper introduces GeopoliticalQA, a benchmark for grounded question answering over heterogeneous geopolitical and strategic intelligence reports, addressing challenges for retrieval-augmented question answering.

Read more → Unsupervised Multimodal Reward Modeling arXiv 计算语言学
