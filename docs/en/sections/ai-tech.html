Frontier Models: Meta's Open-Weight Model Runs Locally, Papers Target Multi-Agent and Reasoning Efficiency

Meta released Muse Spark Open, an open-weight model built with Apple that runs locally on Apple silicon for on-device inference on Macs. In research, ARIA introduces runtime inspection and amendment for LLM-based multi-agent systems, learning interventions during execution to prevent local errors from propagating along agent chains. RoLaQ applies joint rotation and range calibration to 2-bit KV caches in multi-head latent attention, reducing errors in attention matching and value readout from low-bit storage. CoTS uses competitive token selection to decide when latent reasoning is needed, replacing discrete tokens only when necessary. EvolvingBrain proposes an adaptive skill system for multi-modal agents to self-evolve in open worlds.

Research & Governance: Anthropic Gives METR Employee-Level Access; Papers Tackle Benchmark Saturation and Live-Clock Agent Evaluation

Anthropic is granting METR researchers employee-level access to inspect its systems; METR will publish its own assessments of Anthropic's risks, incidents and practices, and Anthropic has waived the right to block publication. In research, one paper examines how to evaluate model capabilities after benchmark saturation, proposing to extract more information from benchmark items. RealtimeBench evaluates LLM agents while games keep running, with 180 tasks across six game types, capturing how latency in reasoning and tool calls affects outcomes. Counterfactual Neighborhood Risk Fields (CNRF) provide an evidence-grounded selective safety framework for vision-language models by defining what a risk score means and when to trust it.
