Developer & Programming: Inline Rendering Trick and LLM Plugin Updates

This briefing covers Lean Rada's inline rendering trick using document.currentScript, plus three tool updates: llm-tools-datasette 0.1.1 fixes breakage for plugins that used httpx without directly depending on it after LLM 0.33 moved to httpx2; llm-echo 0.5 updates simulated token accounting for tool calls and system prompts; and web-edit 0.1a2 adds copy-to-clipboard support for text and image data.
