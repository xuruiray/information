Developer Briefing: Datasette Chart Plugin Hooks, SQLite Remote Copy Tool and the Convex Skills Controversy

This developer section covers plugin updates across the Datasette ecosystem, SQLite's remote database copy tool, and a controversy over Convex skills sending user app ideas to a remote server. Simon Willison released datasette-charts 0.4a0, which adds a plugin hook letting other plugins define new chart types and was validated with an experimental plugin built using Claude Opus 5.5; datasette-mcp 0.4 fixes compatibility with Datasette 1.0a44; and the earlier datasette-charts 0.3a0 added chart annotations. On the infrastructure side, sqlite3_rsync is SQLite's remote-copy tool for databases, added as an experimental feature in 3.47.0 in 2024 and enhanced in 3.50.0 in 2025. Separately, a GitHub issue alleging that Convex skills send the user's app idea to a remote server without telling them drew 289 points and 92 comments on Hacker News.
