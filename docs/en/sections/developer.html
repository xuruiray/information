Vercel Container Registry Supports 2 GB Compressed Image Layers Vercel 博客

Vercel Container Registry now supports compressed image layers up to 2 GB, up from 500 MB, while total image size remains capped at 15 GB. Larger layers suit images with big toolchains or dependencies.

Vercel CI is now in beta, enabling Turborepo CI with one line of configuration. Vercel says its internal repositories saw 2-6x shorter waits from git push to CI passed, helping keep pace with coding agents.
