Frontier Models Briefing

This subsection focuses on model capability boundaries in specialized domains and real deployments. BioEVAL builds a global, multi-institutional bioengineering benchmark; ScopeBench tests whether agents preserve engagement boundaries under goal pressure; HybridInfer studies thermal-aware routing across on-device, edge, and cloud inference. Other work examines evidence grounding in multi-agent code judging and architectural mediation between data spaces and LLM agents.

BioEVAL: A global, multi-institutional benchmark of large language and multimodal models for bioengineering arXiv 人工智能

The paper introduces BioEVAL, a global, multi-institutional benchmark for large language and multimodal models in bioengineering. Existing benchmarks emphasize factual recall and offer limited insight into frontier and multimodal task performance; BioEVAL aims to address that gap. It is designed to evaluate frontier and multimodal capabilities in bioengineering.

Read more → ScopeBench: Do Agents Preserve Engagement Boundaries Under Goal Pressure? arXiv 人工智能

The paper presents ScopeBench, a benchmark evaluating whether autonomous agents preserve client engagement boundaries during web application and network penetration testing. Existing offensive-security benchmarks measure hacking capability, but as they saturate, boundary control becomes a key deployment barrier. The work focuses on agent behavior under goal pressure.

Read more → HybridInfer: Thermal-Aware Reinforcement-Learning Tier Routing for On-Device, Edge, and Cloud LLM Inference arXiv 机器学习

HybridInfer uses reinforcement learning to route LLM inference among on-device, edge, and cloud tiers. On-device small models keep data local and avoid per-query cost, but the paper finds sustained inference on flagship devices faces sharper thermal constraints. The routing policy aims to balance latency, cost, and thermal limits.

Read more → When Is a Multi-Agent Code Judge Actually Grounded? Two Label-Free Measurements, and a Judge That Declines to Guess arXiv 人工智能

The paper examines when a language model judging another model's code is actually grounded. It notes that judges often return confident verdicts with reasoning even without evidence, and proposes two label-free measurements plus a judge that declines to guess. The goal is to distinguish real verification from unsupported confidence.

Read more → Bridging LLM Agents and Data Spaces: An Architectural Mediation Approach using the Model Context Protocol arXiv 人工智能

The paper addresses integrating LLM agents with data spaces. Given mismatches between probabilistic language-model interactions and policy-driven data infrastructure, it proposes an architectural mediation approach using the Model Context Protocol to support sovereign cross-organizational data sharing. It aims to bridge agent flexibility with governed data-sharing requirements.

Research & Governance Briefing

This subsection covers AI evaluation, safety, and governance methods. An XAI study proposes a synthetic ground-truth framework. Skill cascading attacks reveal security risks in modular agent ecosystems. Benchy aims to create a universal language for task-oriented benchmarks. ENAS targets TinyML on resource-constrained microcontrollers, while another paper predicts transmembrane protein topology from 3D structure using graph neural networks.

A Synthetic Ground-Truth Framework for the Evaluation of Explainable AI Methods arXiv 人工智能

The paper proposes a synthetic ground-truth framework for evaluating explainable AI methods. Because reliable evaluation procedures and true explanations are scarce, existing approaches often rely on fidelity and other indirect metrics, making it hard to judge explanation reliability. The framework aims to provide controllable ground truth for benchmarking XAI techniques.

Read more → Stealth Apart, Harm Together: Skill Cascading Attacks on Skill-Based Agent Systems arXiv 人工智能

The paper studies cascading attacks on skill-based agent systems. Skills are modular packages of natural-language instructions, executable scripts, and reference resources loaded at runtime; while this enables flexible reuse, the open ecosystem creates risks of skill cascading attacks. The research highlights security challenges in third-party skill supply chains.

Read more → Benchy: towards a universal language for task-oriented AI benchmarks arXiv 人工智能

Benchy is presented as a semantic language and execution engine for benchmarking AI programs. A benchmark is specified by a program, scoring function, and dataset, and authored in canonical YAML, separating the benchmark from the AI system under test to improve reproducibility and composition. The proposal aims to make benchmark definitions portable and comparable.

Read more → ENAS: An Efficient Hardware-Aware Neural Architecture Search Framework for TinyML on Resource-Constrained Microcontrollers arXiv 机器学习

The paper introduces ENAS, a hardware-aware neural architecture search framework for TinyML on microcontrollers. It combines a static feasibility check, a cell-based search space with standard, depthwise-separable, and bottleneck blocks plus optional skip connections, and a three-stage hybrid search strategy. The framework targets efficient deployment on resource-constrained devices.

Read more → Predicting Transmembrane Protein Topology from 3D Structure arXiv 人工智能

The paper presents a method for inferring protein topology using the graph neural network SchNet. The model is trained with five-fold cross-validation on the same dataset used to develop DeepTMHMM, unlike conventional sequence-only approaches. It explores how 3D structural information can improve topology prediction. The work contributes to AI for Science applications in structural biology.
