The Languages & Frameworks subsection covers development tools and model integration. Anthropic's Claude Sonnet 5.5 improves performance and cost, and is now available on Vercel AI Gateway. Claude Sonnet 5.5 now available on AI Gateway Vercel 博客

Vercel announced that Anthropic's Claude Sonnet 5.5 is now available on AI Gateway as anthropic/claude-sonnet-5.5. The model improves on Claude Sonnet 5 for well-scoped everyday work, from building features and fixing bugs to creating documents, slides, and spreadsheets. On coding tasks, it carries changes through multiple steps and checks its work before reporting completion.

Read more → Search domains without authentication Vercel 博客

Vercel now lets users discover domain names and check availability and pricing without signing in or providing an access token. This works through the Vercel CLI and Domains Registrar API. With the CLI, users search by keyword or domain fragment; the Registrar API checks up to 200 exact domain names in one request and returns whether each is available.

Read more → Vercel Sandbox now supports memory observability Vercel 博客

Vercel Sandbox observability now includes memory usage data. Users can access sandbox memory usage in the dashboard and through the CLI via the vercel metrics command. A new Memory Usage card in the dashboard reports average, P75, and P95 memory across sandboxes, alongside existing CPU usage and data transfer metrics.
