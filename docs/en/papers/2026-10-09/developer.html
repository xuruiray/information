This subsection covers framework features and programming philosophy. Carson Gross argued that programming remains fundamentally about solving problems with computers and learning to control complexity, skills he expects to stay valuable.

Vercel lets Routing Middleware skip receiving request bodies Vercel 博客

Vercel introduced skipMiddlewareRequestBody, which stops client request bodies from being sent to Routing Middleware. The option cuts incoming Fast Origin Transfer usage for middleware invocations and can improve time to first byte, especially for large requests. It should be enabled only when middleware does not read request bodies.

ttok 0.4 released: a token counting CLI tool gets an update Simon Willison

Simon Willison released ttok 0.4, his command-line tool for counting tokens using OpenAI's open-source tiktoken library. The tool had gone unupdated for about two years; this release fixes a Click warning, refreshes CI, and adds a --list-models command for listing available models. It can be run directly via uvx.

Read more → ttok 1.0 released: default tokenizer switches to GPT-5/GPT-6 Simon Willison

After shipping 0.4, Simon Willison upgraded ttok, noticed it still defaulted to the GPT-4 tokenizer, and switched the default to GPT-5/GPT-6, using that change as the occasion to finally ship version 1.0. OpenAI has not confirmed whether GPT-6 uses the same tokenizer.
