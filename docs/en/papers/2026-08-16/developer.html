Don't classify. Hallucinate! Simon Willison

The author shares a fresh approach to tagging blog posts: instead of asking a model to pick from an existing list of thousands of tags, task it with generating candidate tags directly, then match those against the current vocabulary. This avoids overwhelming the model with too many options and simplifies retro-tagging older content.

sqlite-utils 4.2.1 Simon Willison

sqlite-utils 4.2.1 fixes a crashing bug introduced in 4.2: the typing_extensions import required for Self types was not declared as a dependency. Running sqlite-utils directly via uvx no longer triggers the error, restoring stability.

Read more → llm-gemini 0.33 Simon Willison

The llm-gemini 0.33 plugin adds support for Gemini 3.7 Flash, gemini-3.6-flash, gemini-3.5-flash-lite, and two embedding models. It also upgrades compatibility with LLM 0.32, letting users call the latest Gemini models directly from the command line.
