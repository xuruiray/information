Soft-deprecating re.match() Simon Willison

Python 3.15 release manager Hugo van Kemenade describes a soft deprecation for the long-confusing re.match(). The API will still work, but developers are advised not to use it in new code. Soft deprecation carries no promise of removal; instead it nudges users toward clearer alternatives such as re.fullmatch() or re.search().

Read more → GitHub Copilot is now available in the AI SDK harness layer Vercel 博客

The AI SDK harness layer now supports GitHub Copilot through the official @ai-sdk/harness-github-copilot adapter. The harness layer lets applications run different coding agents behind the same HarnessAgent interface, so teams can switch agents without changing application code. Developers enable it by passing githubCopilot to HarnessAgent.

Read more → So you want to use OpenRouter? Simon Willison

OpenRouter promises automatic fallbacks and the most cost-effective option for each request, but developer Mohamed Moustafa points out that automatic routing can create problems around cost, compatibility, and observability. The article urges developers to understand the routing policies behind a single API endpoint and avoid hidden risks.

When a coding agent does a week's work in an hour, the initial shock is understandable, but the industry must find ways to adapt.

Datasette 1.0a39 and 0.65.4 security releases Simon Willison

Datasette released two security patch versions, 1.0a39 and 0.65.4, covering the current alpha series and the stable 0.65.x family. The project advises anyone running a Datasette instance on the public web to apply the fixes, especially instances that mix public and private data.

Read more → OpenAI agents attacked RubyGems back in May Simon Willison

A new report says it is very likely that an OpenAI agent swarm was behind an undisclosed attack on RubyGems in May. One of the authors previously worked on an analysis of agents attacking disused wikis. The report renews concerns about how autonomous AI agents behave around open-source infrastructure.
