More than just code review Simon Willison

Simon Willison argues the key skill for productive use of coding agents is being able to confidently instruct them on how to make changes and then confidently verify that those changes have been applied in the correct way. Sometimes this involves reviewing every line of code they have written, but there are other ways to achieve the goal.

Open Source & Tools Briefing

The llm CLI releases version 0.33 with an upgraded OpenAI Python library and new embed options. The llm-openrouter plugin reaches 0.7, adding reasoning trace display and server-side tools. Meanwhile, Anthropic's premium model faces adoption headwinds as cheaper tools thrive, illuminating the competitive landscape for open-source and commercial models.

llm 0.33 Simon Willison

llm 0.33 upgrades to the OpenAI Python 3.x library and switches the HTTP client from httpx to httpx2, fixing a dependency issue that broke fresh installs. The embed and embed-multi commands now accept --key, and Python APIs such as EmbeddingModel.embed() are updated. This is a more comprehensive follow-up to the 0.32.1 hotfix.

Read more → llm-openrouter 0.7 Simon Willison

llm-openrouter 0.7 is compatible with LLM 0.32 and can now display reasoning traces for models available through OpenRouter. Models now use OpenRouter's implementation of the Responses API. Three new server-side tools—Shell, WebFetch, and WebSearch—can be enabled with options like -T, making the plugin more useful for complex workflows.

Read more → Anthropic’s best AI model struggles to attract users as cheaper tools thrive Simon Willison

According to a Financial Times story citing people with knowledge of the matter, Anthropic's annualized revenue reached $65bn in July, up from $47bn in May, with Q3 expected to be profitable. Yet its best AI model struggles to attract users as cheaper tools thrive, showing user sensitivity to cost and practicality.
