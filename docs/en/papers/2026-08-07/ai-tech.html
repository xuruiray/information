Frontier Models Briefing

The frontier-models subsection centers on evaluation and capability expansion. New benchmarks target comprehensive EEG understanding, financial-agent rubrics, and personalized memory for LLM assistants. In parallel, OpenAI partnered with the American Psychological Association to support evidence-based guidance on responsible AI and youth mental health.

BrainBench: Benchmarking Large Language Models for Comprehensive EEG Understanding arXiv 人工智能

EEG analysis goes beyond assigning labels to recordings, requiring workflows that connect natural-language instructions, signal processing, quantitative evidence, and scientific interpretation. The new BrainBench benchmark targets this comprehensive understanding to assess how well large models grasp EEG data.

Read more → FinProBench: Evaluating Financial AI Agents with Role-Grounded Rubrics Derived from Professional Deliverables arXiv 人工智能

Evaluating financial AI agents requires criteria aligned with real professional work. Existing rubric methods derive standards from prompts or model outputs, overlooking tacit knowledge in practitioner deliverables. FinProBench introduces a benchmark that extracts role-grounded rubrics from professional deliverables for realistic financial tasks.

Read more → FinPerMA: A Theory-Informed, Event-Grounded Personalized-Memory Benchmark for LLM Agents arXiv 人工智能

LLM agents are increasingly used as personalized assistants in high-stakes fields like financial advising, yet it remains unclear whether they can maintain and update individualized user models over long horizons. FinPerMA provides a theory-informed, event-grounded benchmark for evaluating personalized memory.

Read more → An Explainable LLM Agent Layer for Open-World Anomaly Detection in Oil Wells arXiv 机器学习

Existing oil-well anomaly detection pipelines can answer what happened but not why. This work adds an explainable agent layer to large-model systems, providing natural-language explanations within an open-world learning framework to improve trust in anomaly diagnosis.

Research & Governance Briefing

The research & governance subsection presents diverse academic work: Monte Carlo tree search for generating multimodal reports from tables, end-to-end multilingual metaphor processing, open-vocabulary tactile recognition from low-cost pressure arrays, federated learning for aircraft-engine prognostics, and cycle-aware time-series forecasting.

Monte Carlo Tree Search for Table-to-Multimodal Report Generation arXiv 人工智能

Generating professional multimodal reports with both textual analysis and visual charts from tabular data is a core data-intelligence challenge. Existing methods rely on fixed linear pipelines and isolated subtasks, impeding joint optimization. This work applies Monte Carlo tree search to overcome these limits.

Read more → Towards End-to-End Multilingual Metaphor Processing: Integrating Detection, Translation, and Evaluation arXiv 计算语言学

Metaphorical language remains a major challenge for multilingual NLP because interpretation and translation require reasoning beyond literal meaning. Existing work treats detection, machine translation, and evaluation separately. This paper proposes an end-to-end framework to integrate these stages and improve metaphor understanding.

Read more → Tactus: Open-Vocabulary Object Recognition from Low-Cost Pressure Arrays arXiv 机器学习

Resistive pressure arrays are among the cheapest and most widely used tactile sensors, yet tactile representation learning has focused on optical sensors. Tactus, an open model, answers text queries from pressure data alone and demonstrates open-vocabulary recognition on the STAG benchmark.

Read more → Robust and Personalized Federated Learning for Aircraft-Engine Prognostics under Benign and Adversarial Client Heterogeneity arXiv 机器学习

Federated learning lets fleet operators train remaining-useful-life models from engine telemetry without sharing raw data. This study addresses both benign heterogeneity—different operating conditions and fault modes—and adversarial client behavior, proposing robust and personalized learning methods.

Read more → CAMP: A Cycle-Aware Multi-Scale Patch Mixer for Time Series Forecasting arXiv 机器学习

Real-world time series are often governed by recurring patterns, but dominant periods vary across datasets, settings, and windows. Existing cycle-aware forecasters rely on a single dataset-level period. CAMP uses a cycle-aware multi-scale patch mixer to capture periodicity at multiple granularities and boost forecasting.
