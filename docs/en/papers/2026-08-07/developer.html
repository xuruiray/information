Infrastructure & Data Briefing

This section highlights Datasette 1.0a38, which fixes a SQL injection vulnerability affecting instances serving a mix of public and private tables with permission-based access. Site administrators are advised to disable the execute-sql permission in such configurations. This release underscores the importance of robust access control and security hardening in data publishing tools.

datasette 1.0a38 Simon Willison

Datasette 1.0a38 has been released, fixing a SQL injection vulnerability that affects instances serving a mix of public and private tables within the same database, with access controlled by the Datasette permissions system. Site administrators are advised to disable the execute-sql permission in such configurations. This release is part of the 1.0 alpha series and underscores security hardening for data tools.
