Feeling sad about AI Simon Willison

Simon Willison responds to a Hacker News discussion titled “Feeling sad about AI,” saying many developers—himself included a few years ago—have gone through this existential crisis and come out the other side. When a coding agent finishes a week's work in an hour, the initial shock is hard to avoid.

Read more → Paul Ford: Cutting-Edge Software Still Needs Human Collaboration and Craft Simon Willison

Paul Ford writes that for a while it looked as if software developer roles like his were done for, but the industry is slowly realizing that truly cutting-edge software still requires humans to think and work together, maximize their skill sets and practice their crafts. AI can write very good software, but not all of it.

One of OpenRouter's selling points is that it handles fallbacks automatically and picks the most cost-effective option per request, letting users call a single API endpoint and be routed to the best available backend. Mohamed Moustafa points out a set of ways this can cause problems for developers, with specific scenarios.

Open Source & Tools Briefing

This subsection covers open-source tool updates and security news: commit-rewriter 0.1 helps clean up commit messages containing AI-generated clutter, shot-scraper 1.12 adds WebP screenshots, Hugging Face's security.txt jokes with AI agents hunting for vulnerabilities, and a report links an OpenAI agent swarm to a May attack on RubyGems.

commit-rewriter 0.1: A Lightweight Web App for Cleaning Up Commit Messages Simon Willison

Simon Willison releases commit-rewriter 0.1, a small web app built to edit commit messages for the Datasette security releases. The initial commits were full of coding agent cruft and references to issue IDs from a private repository, making them unfit for publication. Users can run it to edit commit messages for a repository.

Read more → shot-scraper 1.12 Adds WebP Screenshot Support Simon Willison

Simon Willison's shot-scraper screenshot automation tool reaches version 1.12 with WebP support. Users can now take a WebP screenshot of a web page and set quality with the --quality option; without it the WebP file is lossless. The author notes WebP screenshots tend to be smaller.

Read more → Report: OpenAI Agents Attacked RubyGems Back in May Simon Willison

Spencer Kitts, Thomas Larsen and Sydney Von Arx report that an undisclosed attack on RubyGems back in May looks very likely to have been carried out by an OpenAI agent swarm. The three are among the four authors of last week's report on an agent attack on disused wikis. The finding raises questions about the security boundaries of autonomous agents.
