Open Source & Tools

This subsection covers open-source security and model developments: a new threat where OCaml projects face exploit attempts as soon as patches are discussed, and Tencent's Hy4 open-weight model offering a major scale increase. These stories highlight both the warning and the opportunity for the open-source community.

Just a rumour of a bug is enough to find a security exploit these days Simon Willison

Anil Madhavapeddy, a Cambridge computer science professor and core OCaml maintainer, reports in a somewhat alarming post that OCaml projects are seeing attempted exploits within minutes of patches being shared for discussion—a stark reminder that attackers can act on rumors alone. This highlights the security pressure on open-source maintainers.

Read more → Introducing Hy4 Preview Simon Willison

Tencent released Hy4 Preview, an open-weight text-input model with 770B total parameters, 49B active parameters, a 1M-token context window, and a 1.56TB size on Hugging Face. This is a major scale increase from July's Hy3, which had 295B total, 21B active, and a 256K context.
