Measuring the Microtask Eligibility Gap: When Is an Off-the-Shelf SLM Enough for an Agent Harness? The study asks whether off-the-shelf small language models meet practitioner-defined thresholds for microtasks around a frontier LLM planner, such as auto-approving shell commands, writing memory, selecting tools and ranking past turns. It introduces a method to measure the microtask eligibility gap. arXiv 人工智能 Gradient-Aligned Pair Selection for Personalized Preference Optimization The paper addresses personalizing LLMs by aligning generation with individual user preferences rather than aggregate quality. Within direct preference optimization (DPO), it proposes a gradient-aligned pair selection method to improve personalized preference learning. It argues that DPO's effectiveness in personalized settings depends on how preference pairs are selected, and introduces a gradient-aligned approach to choose pairs that better reflect user-specific preferences. arXiv 人工智能 Heavy-Tailed Memory Traces in Long-Horizon Language Agents The paper argues that long-horizon language agents rely on external memory as a frozen world model, yet current systems are judged mainly by task success or token cost. It highlights the shape of memory use: under finite context and repeated retrieval, agent memory can concentrate on a few entries, showing heavy-tailed traces. arXiv 人工智能
