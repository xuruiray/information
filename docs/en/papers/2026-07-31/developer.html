Performance Monitoring & CDN

Vercel's CDN will pass through Server-Timing headers, bringing backend metrics to browsers and the Performance API, improving observability.

Vercel CDN to Pass Through Server-Timing Response Headers Vercel 博客

Starting August 10, 2026, Vercel's CDN will stop stripping Server-Timing headers and pass them to the client. Developers can report backend metrics like database query time and cache hits, visible in browser network panels and via PerformanceServerTiming entries.
