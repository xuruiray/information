This subsection highlights open-source tooling. The release of llm-openrouter 0.7 brings compatibility with LLM 0.32 and adopts OpenRouter's Responses API, improving support for reasoning models. llm-openrouter 0.7 Simon Willison

The llm-openrouter plugin is now at version 0.7, compatible with LLM 0.32 and switching to OpenRouter's Responses API for better reasoning model support. It adds three server-side tools—Shell, WebFetch, and WebSearch—that developers can enable via command-line options, expanding AI workflows in the terminal.
