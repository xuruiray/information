Claude Code adds AGENTS.md support for project instructions Simon Willison

Starting with version 2.1.277, Claude Code will look for and use AGENTS.md when a folder has no CLAUDE.md. The support is built on Claude Code mods, an upcoming way to customize the Claude Code harness, and ships as a built-in mod that users will later be able to adapt for their own project instructions.

Read more → GLM 5.3 FlashX now available on AI Gateway Vercel 博客

GLM 5.3 FlashX, a high-speed serving option for Z.ai's multimodal coding model, is now available on AI Gateway. It delivers inference at roughly 200 tokens per second for faster streamed responses, aimed at coding agents, tool loops and interactive applications, and is invoked with the zai/glm-5.3-flashx identifier.

Read more → Sub-second artifact deployments are now supported in Vercel CLI Vercel 博客

Vercel CLI can now deploy static artifacts to Vercel in under one second. Vercel automatically detects eligible deployments, and valid artifacts skip the build step and immediately return a live URL, making it easier to share prototypes, publish HTML reports or preview pages generated by coding agents.

Read more → Turbo build machines can now be enabled per deployment Vercel 博客

Turbo build machines can now be enabled on any individual deployment, letting teams add resources temporarily without changing project settings. Teams can opt in by adding #VERCEL_BUILD_MACHINE=TURBO to a Git commit message, running vc deploy --turbo with CLI 59.20.0 or later, or setting buildMachine in configuration.

Open Source & Tools Briefing

Security and ecosystem maintenance dominate this subsection: the crates security team warns of targeted attacks on prominent Rust maintainers, a Next.js image-optimization report leads to an upstream libheif vulnerability that is reproduced and fixed, datasette-auth-github ships version 1.0, and a GitHub Podcast episode debates reading code, RAG and MCP.

Be alert: targeted attacks on prominent Rustaceans Simon Willison

Adam Harvey and the crates security team warn of an ongoing campaign targeting rust-lang members and owners of popular crates. Attackers try to compromise devices and accounts so they can publish malware, using tactics such as setting up video calls for something that sounds positive.

Read more → Reproducing, disclosing, and fixing the libheif vulnerability with Hacktron and the maintainers Vercel 博客

In August 2026 Hacktron reported a suspected remote code execution issue in Next.js image optimization, but the vulnerable code turned out to be upstream in libheif, an AVIF decoder used by Next.js, ImageMagick, WordPress, sharp and much of the web. Vercel and the maintainers then reproduced, disclosed and fixed the flaw.

Read more → datasette-auth-github 1.0 Simon Willison

The datasette-auth-github plugin has reached version 1.0. The author noticed that authenticated sessions on the agent.datasette.io demo site were not lasting long, because the plugin set cookies without a Max-Age parameter so they expired at the end of a browser session; the release fixes that behavior.

A new episode of the GitHub Podcast examines questions developers are debating about AI tooling: whether you should still read the code, whether RAG is dead, and whether Skills have killed MCP. The episode collects the GitHub team's takes on these and other hot topics.
