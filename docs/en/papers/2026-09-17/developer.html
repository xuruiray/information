Languages & Frameworks Briefing

This subsection covers framework and platform changes. Claude merged Cowork and chat into one product, letting tasks continue after a laptop is closed. Vercel added Mem0 memory integration to its Marketplace, tightened deployment retention for Hobby teams, and cut build start times by 64% for Secure Compute and Static IP builds.

Claude Cowork and chat are now one Claude Simon Willison

Claude announced that Cowork and chat are merging into one product. Users can bring a quick question or hand over a report due at noon, and Claude takes it from there, even after the laptop has been closed.

Read more → Mem0 joins the Vercel Marketplace Vercel 博客

Mem0 is now available as a native integration on the Vercel Marketplace, giving AI agents and apps long-term memory that remembers user preferences, facts and context across sessions. It installs directly from the Marketplace with billing on the Vercel invoice, and no separate account or key management.

Read more → Hobby projects now retain fewer deployments to free up storage Vercel 博客

Vercel changed deployment retention for Hobby projects so that old deployments past the 30-day retention window are deleted sooner. Hobby teams get 10GB of deployment storage, and exceeding the limit can block further deployments until space is freed up.

Read more → Secure Compute and Static IP builds start 64% faster Vercel 博客

Vercel says builds using Secure Compute or Static IPs now start 64% faster, with average time from deployment creation to build start falling from 6.7 seconds to 2.4 seconds. These builds now use prewarmed containers with the network configuration attached at startup.

Open Source & Tools Briefing

This subsection covers open-source and tooling news. Datasette released 1.0a40 with plugin background tasks and 0.65.5 with a permission-bypass fix. GitHub described porting its Copilot agent runtime to Rust with agent assistance, and a quoted excerpt argues models should not be treated as having feelings or rights.

datasette 1.0a40 Simon Willison

Datasette released 1.0a40, carrying the same security fix as 0.65.5 along with new features and bug fixes. Plugins can now launch and manage background tasks through datasette.add_background_task(), and the project's internal client has moved to httpx.

Read more → datasette 0.65.5 Simon Willison

Datasette released 0.65.5, fixing a security issue where a trailing newline in a requested table name could bypass table permissions and expose private rows. The issue was reported via GHSA-h547-rmjf-5m2m.

Read more → Quoting Mustafa Suleyman Simon Willison

Mustafa Suleyman argues that models should not be treated as having feelings, preferences, rights or any entitlement to our welfare. He says consciousness is the foundation of our ethical, legal and political systems, and that granting another entity such rights is not justified by evidence and makes AI containment and alignment harder.
