Simon Willison shipped a Newsletters page indexing his free weekly Substack and sponsors-only monthly updates. He built the feature almost entirely with his voice, using Codex voice mode in the ChatGPT desktop app while cooking dinner.

ttok is a CLI for counting tokens built on OpenAI's open source tiktoken library. After releasing 0.4, the author switched the default tokenizer from GPT-4 to newer GPT-5/GPT-6 models and used that as the reason to ship 1.0; it runs directly via uvx ttok.
