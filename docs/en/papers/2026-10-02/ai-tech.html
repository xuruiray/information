Frontier Models: Agent and Reasoning Advances

This subsection covers frontier models and agent techniques: measuring whether off-the-shelf small models can handle microtasks around a planner, gradient-aligned pair selection for personalized preference optimization, heavy-tailed memory in long-horizon agents, causal world models for modular agents, and Hermes for unlocking test-time scaling through contextual reasoning.

Measuring the Microtask Eligibility Gap: When Is an Off-the-Shelf SLM Enough for an Agent Harness? arXiv 人工智能

The study asks whether off-the-shelf small language models meet practitioner-defined thresholds for microtasks around a frontier LLM planner, such as auto-approving shell commands, writing memory, selecting tools and ranking past turns. It introduces a method to measure the microtask eligibility gap.

Read more → Gradient-Aligned Pair Selection for Personalized Preference Optimization arXiv 人工智能

The paper addresses personalizing LLMs by aligning generation with individual user preferences rather than aggregate quality. Within direct preference optimization (DPO), it proposes a gradient-aligned pair selection method to improve personalized preference learning. It argues that DPO's effectiveness in personalized settings depends on how preference pairs are selected, and introduces a gradient-aligned approach to choose pairs that better reflect user-specific preferences.

Read more → Heavy-Tailed Memory Traces in Long-Horizon Language Agents arXiv 人工智能

The paper argues that long-horizon language agents rely on external memory as a frozen world model, yet current systems are judged mainly by task success or token cost. It highlights the shape of memory use: under finite context and repeated retrieval, agent memory can concentrate on a few entries, showing heavy-tailed traces.

Read more → When Do Causal World Models Help Modular LLM Agents arXiv 人工智能

The study focuses on LLM agents acting through modular systems such as order, payment, inventory and shipment services, where actions in one module change valid transitions in another. It examines the limits of standard world models fitted to observational traces and analyzes when causal world models help intervention-time planning.

Read more → Hermes: Learning Contextual Reasoning Unlocks Test-Time Scaling arXiv 机器学习

The paper introduces Hermes, focusing on how test-time scaling improves model performance by allocating additional inference compute. Using this compute effectively across multiple context windows requires deciding how to allocate fresh contexts and what information to carry between them. The authors call this contextual reasoning and show that learning it unlocks test-time scaling.

Research & Governance: Benchmarks, Alignment and Interpretability

This subsection covers AI research and governance: a large-scale text-to-SPARQL benchmark for building knowledge graphs, activation-conditioned self-distillation, proof-carrying selective recommendation for public services, evaluation of contextual value alignment in LLMs, and analysis of how system prompts modify transformer computation.

Build2SPARQL: A Large-Scale Text-to-SPARQL Benchmark Dataset for Building Knowledge Graph Querying arXiv 人工智能

Building automation systems are increasingly represented as semantic knowledge graphs using ontologies such as Brick and ASHRAE 223P, creating a machine-readable substrate for AI applications. The paper introduces Build2SPARQL, a large-scale text-to-SPARQL benchmark dataset for evaluating natural-language query translation over building knowledge graphs.

Read more → Activation-Conditioned Self-Distillation arXiv 机器学习

The paper studies on-policy self-distillation, where a model serves as its own teacher to provide dense supervision for reasoning, often through reference-solution conditioning. It argues that privileged information alone does not ensure effective token-level supervision throughout long responses, and introduces activation-conditioned self-distillation.

Read more → EviGraph: Proof-Carrying Selective Recommendation over Temporal Public-Service Knowledge Graphs arXiv 人工智能

Public-service recommendations require evidence matching the requested service, scope and date, yet treating every missing detail as decisive can withhold useful recommendations. The paper introduces EviGraph, which distinguishes critical decision requirements from information that can remain unresolved, enabling proof-carrying selective recommendation over temporal public-service knowledge graphs.

Read more → ContextAdapt: Evaluating Contextual Adaptation and Value Alignment in LLMs arXiv 计算语言学

The paper examines how values such as honesty, autonomy and confidentiality depend on the context in which a decision is made. It introduces ContextAdapt to evaluate whether LLMs appropriately adapt and align with these values in context, asking whether models can correctly interpret and apply general principles across different situations.

Read more → The System Prompt Illusion: How Instruction Preambles Modify Computation in Language Models arXiv 计算语言学

System prompts are the primary lever practitioners use to control language model behavior, yet their actual effect on computation inside the transformer remains poorly understood. Across 17 instruction-tuned models spanning 8 architecture families and 1.5B to 72B parameters, the paper uses methods such as Centered Kernel Alignment to analyze how instruction preambles modify computation.
