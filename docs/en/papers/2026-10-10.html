Lead Story
Deno is joining Cloudflare

Cloudflare is acquiring Deno outright. The Deno team had released celld, an open-source implementation of the Durable Objects pattern from Cloudflare Workers. With the acquisition, Cloudflare aims to build on celld to make workerd self-hosting a first-class supported way to build and run applications using the Workers platform.
