Vercel Passport is now generally available, enabling teams to protect deployments with their own identity provider. Visitors authenticate via Okta, Microsoft Entra ID, or any OIDC provider before viewing, and Vercel forwards a signed identity token to the deployment so application code can build on who the visitor is.

Open Source & Tools: Performance Optimization and Ecosystem Expansion

Open source & tools: llm-mcp-client adds MCP client support to the LLM toolchain; GitHub's branch-free loop case-folds source code at >45 GiB/s per core; Chat SDK adds Teams reactions and ephemeral messages; Slack Emoji Maker offers a simple editor for Slack-sized emoji.

llm-mcp-client 0.1a0 Simon Willison

llm-mcp-client 0.1a0 is now available, adding Model Context Protocol client support to LLM tooling. The release aims to simplify how developers connect MCP-compatible services to their model workflows. Additional details are available in the accompanying blog post.

Read more → Don’t stop early: Case-folding source code at memory speed GitHub 博客

GitHub engineers describe a branch-free loop and byte-space arithmetic enabling case-folding of every byte in code search at >45 GiB/s on a single core. This optimization highlights how careful low-level design can dramatically accelerate a core search operation.

Read more → Chat SDK now supports reactions and ephemeral messages on Teams Vercel 博客

Chat SDK's Microsoft Teams adapter now supports reactions and ephemeral messages through the same API as other adapters. Bots can add or remove reactions on Teams messages, and call thread.postEphemeral() or channel.postEphemeral() to send native, targeted messages that only the intended user sees, such as permission prompts.
