Read more → datasette 1.0a41 Simon Willison

Datasette 1.0a41 is released. Alec Garcia added OpenTelemetry support in this version, and all of Datasette's modal dialogs were refactored into a single Web Component that is now documented for other plugins to use. The update focuses on observability and reusable interface components.

Read more → Push images to Vercel Container Registry from GitHub Actions Vercel 博客

Vercel released a vercel/vcr-action/login action that lets GitHub Actions push container images to Vercel Container Registry using GitHub OIDC. The action exchanges the workflow's OIDC token for a short-lived Vercel access token and logs in to vcr.vercel.com. This removes the need to store long-lived registry credentials in CI.

State of agent skills Vercel 博客

The skills.sh registry grew to one million agent skills in seven months and recorded nearly 280 million installs. A skill gives an AI agent reusable instructions for a particular job, supplying context on how a specific person, team, or company does that work. Agents are capable but generic without such context.

GitHub Security Lab explains how to use a new fuzzing taskflow based on the GitHub Security Lab Taskflow Agent AI framework. The approach brings AI into security testing workflows, helping developers automate and scale fuzzing work. The post describes practical steps for applying the taskflow.

Read more → commit-rewriter 0.2 Simon Willison

commit-rewriter 0.2 is released with support for branches other than the default branch. Users can run it against another branch with uvx commit-rewriter --branch other. The tool is designed for rewriting Git commits. This small update improves everyday Git history editing workflows for developers.
