Languages & Frameworks: Vercel security challenge, managed keys, Qwen's small-model surprise

In languages and frameworks, Vercel announced a $1 million hacker challenge for Sandbox, added a managed JWT signing feature that keeps private keys out of code, and enabled direct deployments from users' GitHub repositories. Meanwhile, Qwen 3.8 27B scored 52 on the Artificial Analysis Intelligence Index, matching much larger models like GPT-5.6 Luna.

$1 million hacker challenge for Vercel Sandbox Vercel 博客

Vercel is running a $1 million hacker challenge for its Sandbox microVM, inviting researchers to break out of the sandbox. Recent research and incidents show that untrusted code can escape containment without crossing a VM boundary, underscoring the need for stronger defenses.

Read more → Sign JWTs from your Functions without managing private keys Vercel 博客

Vercel KMS now lets you sign JWTs and arbitrary messages from Vercel Functions using managed asymmetric keys. Private keys never enter code or environment variables; functions authenticate via Vercel OIDC tokens, and verifiers only need the public key. This removes the need to handle private keys in serverless code, reducing security risk and simplifying key management.

Read more → Qwen 3.8 27B scores 52 on the Artificial Analysis Intelligence Index Simon Willison

Qwen 3.8 27B scored 52 on the Artificial Analysis Intelligence Index, tying GPT-5.6 Luna (max) and just one point behind GLM-5.2 and DeepSeek V4 Pro, which have 753B and 1.7T parameters respectively. The 27B model's result is astonishing. This suggests that smaller models are closing the gap with frontier systems at a fraction of the cost.

Read more → Vercel for Platforms can now deploy from your users' GitHub repositories Vercel 博客

Teams on Vercel for Platforms can now deploy directly from their users' GitHub repositories without requiring the Vercel GitHub App. Pass a read-only gitAccessToken with gitSource to fetch source and build. This simplifies the integration of user-owned repositories into multi-tenant platforms, enabling a smoother onboarding experience for end users.
