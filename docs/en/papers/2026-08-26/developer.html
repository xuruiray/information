Languages & Frameworks: Agent Code Execution and Python Migration

This subsection highlights language and framework updates. Vercel introduces Run SDK for secure agent code execution and Connect to replace long-lived credentials with short-lived ones. Meanwhile, EVE Online begins migrating from Stackless Python 2.7 to Python 3 using futurize, marking a major milestone.

Introducing Run SDK: Secure Eval for Your Agents Vercel 博客

Vercel introduces Run SDK for securely executing TypeScript programs written by agents. When such programs touch real applications, some steps require authentication while others need human approval. Executing code with eval grants the same access as the surrounding application, including secrets and internal services, and leaves no durable trail.

Read more → The End of Credential Sprawl for Agents Vercel 博客

Every useful agent extends beyond the codebase, posting to Slack, opening PRs, querying Snowflake, or calling internal APIs. This reach is valuable but risky, as it traditionally required long-lived tokens. Vercel Connect replaces long-lived tokens with short-lived credentials, reducing exposure.

EVE Online has been a compelling case study in Python at scale for over 20 years, running on Stackless Python since 2003 and last upgraded to 2.7 in 2010. It now begins migration to Python 3 using the futurize script.
