Infrastructure and data: Vercel Sandbox images and PrivateLink endpoint updates

All Vercel Sandbox runtimes now use Vercel Managed Images; legacy runtimes such as node22 use open-source images from the vercel/sandbox repository, distributed via Vercel Container Registry, and new sandboxes provide 64 GB storage. Enterprise teams on Secure Compute can create and manage AWS PrivateLink endpoints from the Vercel dashboard; endpoints live in the team’s dedicated VPC and are shared by connected project environments. The Workflow SDK can delete a finished run’s stored data on demand, including inputs, outputs, hook payloads and error traces, to meet compliance and security requirements.
