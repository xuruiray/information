condense-json 1.0 Simon Willison

condense-json 1.0 is out after a year and a half of development. The library compresses JSON data to reduce storage and transfer overhead; the author applied sensible, non-disruptive fixes before the stable release. It offers a simple way to shrink JSON payloads while preserving compatibility for existing users.
