Lead Story
Using Parseable with Datasette for OpenTelemetry traces

Simon Willison shares a TIL on combining Parseable, a new observability platform, with Datasette for OpenTelemetry traces. Parseable offers an AGPL-licensed Rust implementation in a single binary, plus enterprise and hosted options. Since Datasette 1.0a41 added OpenTelemetry support, this setup lets developers inspect and query trace data locally. The post is a practical guide for engineers evaluating lightweight observability and data exploration tools.
