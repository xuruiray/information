Languages & Frameworks

Vercel shipped several updates relevant to agent development: Hermes Agent can now use Vercel AI Gateway and Sandbox, coding agents orchestrated by Herdr each run in isolated microVMs, Skill Packs allow sharing agent skills via skills.sh, and Audit Log Drains add Datadog, Splunk, and Panther as destinations. Together, these improvements streamline agent builds, reduce local machine risk, and make team-level skill sharing and observability more practical.

Vercel AI Gateway and Vercel Sandbox now available on Hermes Agent Vercel 博客

Vercel announced that its AI Gateway and Sandbox are now integrated with Hermes Agent. Developers can access more than 200 models through AI Gateway with no markup on tokens; agent commands run in isolated Sandbox microVMs, and every request appears in the AI Gateway dashboard for centralized usage and spend tracking.

Read more → Audit Log Drains now support Datadog, Splunk, and Panther Vercel 博客

Vercel’s Audit Log Drains now support Datadog, Splunk, and Panther, alongside existing custom HTTPS endpoints and Amazon S3. Enterprise teams can forward activity logs and extra audit metadata to these platforms in real time, strengthening security compliance and observability.

Read more → Skill packs are now available on skills.sh Vercel 博客

Vercel launched Skill Packs on skills.sh, enabling users to bundle multiple agent skills into shareable collections. Packs can be built from community skills, local folders or zips, and public or private GitHub repositories, then shared via a unique unlisted URL to standardize skills across a team.

Read more → Give every agent in Herdr its own Vercel Sandbox Vercel 博客

Vercel’s new Herdr integration lets terminal coding agents such as Claude Code, Codex, and OpenCode each run in their own isolated Vercel Sandbox. A tmux-style manager orchestrates them side by side in panes, and nothing an agent runs or edits touches the developer’s machine.
