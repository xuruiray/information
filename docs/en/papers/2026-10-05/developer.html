We're going to need default hard budget caps on pretty much everything Simon Willison

The post argues that pay-by-usage services and APIs should offer default hard budget caps, cutting usage off and returning errors after a set monthly spend, rather than soft caps that only send a warning email. Hard limits, it says, will be needed across a growing range of products.
