Vercel Agent Now Installs Private Packages from npm and Custom Registries Vercel 博客

Vercel Agent can now install private dependencies from npm and custom registries using credentials stored as shared environment variables on Vercel. npm, pnpm and classic Yarn running in Agent sessions authenticate the same way they do in Vercel builds. To get started, add a shared environment variable for the Development or Preview environment and use NPM_TOKEN for private packages hosted on npm.

Read more → AI Gateway Adds Browserbase Search and Fetch Tools Vercel 博客

Browserbase Search and Fetch are now available through Vercel's AI Gateway, letting models find relevant pages, retrieve their contents and access current information. The tools work across model providers with a single API key, alongside Browserbase's existing AI SDK and Vercel Marketplace integrations.

Read more → Vercel Renames Edge Requests Usage Metric to CDN Requests Vercel 博客

Vercel has renamed its Edge Requests usage metric to CDN Requests. The change is naming only: pricing, limits and how usage is measured are unchanged. The new name appears on the usage dashboard, the Observability Events chart, usage notifications and invoice line items, reflecting that these requests are served by Vercel's CDN.

Read more → He Built This City: Joe Macken's Model of New York Simon Willison

Simon Willison visited the Museum of the City of New York and saw "He Built This City: Joe Macken's Model," a 50-by-27-foot model of the city built over 21 years from balsa wood and cardboard. He said it exceeded his already high expectations and noted that the exhibition closes on 12 October.
