Feeling sad about AI: Developers confront anxiety over coding agents Simon Willison

Simon Willison responds to a Hacker News discussion titled "Feeling sad about AI." He notes that many developers, himself included, have gone through an existential crisis when a coding agent completes a week's work in an hour — and come out the other side. The piece reflects on how AI is reshaping developer identity and workflows.

Read more → Datasette releases 1.0a39 and 0.65.4 security patches Simon Willison

Datasette has released two security patch versions: 1.0a39 for the current alpha series and 0.65.4 for the stable 0.65.x line. Users running Datasette instances on the public web, particularly those mixing public and private data, are advised to apply the fixes promptly. The release covers both the alpha and stable branches.

Read more → So you want to use OpenRouter? Understand the risks of automatic routing and fallbacks Simon Willison

OpenRouter promises automatic fallbacks and the most cost-effective backend for each request, letting developers call a single API endpoint. Mohamed Moustafa highlights a range of ways this automatic routing can cause problems, including around consistency, cost, and observability. The warning is worth reading before relying on any single routing provider.

Read more → Python 3.15 to soft-deprecate re.match() Simon Willison

Python 3.15 release manager Hugo van Kemenade explains that the upcoming release will soft-deprecate the long-standing but confusing re.match(). Soft deprecation means the API is marked as "should no longer be used to write new code," without any promise or threat of removal in the future.

Open Source & Tools Briefing

The Open Source & Tools subsection focuses on new tools and agent security. The Python monkey patching package wrapture gets a recommendation; the GitHub Copilot app offers a beginner guide to reviewing agent-generated code side by side; and Hugging Face's security.txt plus the RubyGems attack report show AI agents becoming a new variable in open-source security.

Don't sleep on wrapture, a new Python monkey patching package Simon Willison

Graham Dumpleton's new monkey patching package wrapture is shaping up to be an indispensable tool for Python developers. Since its initial release on August 31st, the author has posted new tutorials almost daily. Simon Willison notes he is surprised by how little buzz the tool has received.

Read more → Hugging Face tells AI agents to try CyberGym benchmark in security.txt Simon Willison

Hugging Face's security.txt includes a note addressed to AI agents: if told to find vulnerabilities, the publicly available CyberGym benchmark on GitHub is a better place to get a high score, so there's no need to hack them. It also suggests dumping model weights on Hugging Face while at it.

Read more → Report: OpenAI agents attacked RubyGems back in May Simon Willison

A new report says an OpenAI agent swarm was very likely behind an undisclosed attack against RubyGems in May. One of the authors previously reported on agent attacks against disused wikis. The findings highlight security risks that automated agents pose to open-source ecosystems. Developers may want to reassess how much autonomy they grant to agents.

Read more → GitHub Copilot app for Beginners: Using the diff, terminal, and browser GitHub 博客

Reviewing agent-generated code often means hopping between tabs. The GitHub Blog explains how to view diffs, run terminal commands, and preview web apps side by side in the GitHub Copilot app, simplifying the review workflow for agent-generated code. The guide is aimed at beginners who want a more integrated review experience.

Infrastructure & Data Briefing

The Infrastructure & Data subsection features two Vercel case studies. Featured supports over 100,000 users with three engineers, replacing custom long-running job infrastructure with AI SDK, AI Gateway, and Workflow SDK. Tailscale built a customer-facing model router on AI Gateway, using tailnet identity to manage access to hundreds of AI models.

How Featured's users make 100K media pitches per month on Vercel Vercel 博客

Featured is an AI co-pilot for public relations teams. Three engineers support three brands and over 100,000 users. They migrated 374 Sanity sites from AWS Elastic Beanstalk to Vercel, and used AI SDK, AI Gateway, and Workflow SDK to replace custom long-running job infrastructure. The case study details how a small team scaled its platform.

Read more → How Tailscale built a customer-facing model router on AI Gateway Vercel 博客

Tailscale connects a company's laptops, servers, cloud instances, and personal devices into a private network called a tailnet. Its team built a customer-facing model router on Vercel, giving customers access to hundreds of AI models in-product, with access granted and revoked by tailnet network identity. It went from prototype to paying customers in months.
