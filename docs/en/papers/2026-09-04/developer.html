Development & Programming: AI Toolchain Upgrades and Storage Infrastructure Innovation

This edition of Development & Programming highlights fresh moves in AI coding assistants and cloud infrastructure. OpenAI's GPT-6 Astra is rolling out to select organizations today and will reach ChatGPT Plus, Pro, Business, Enterprise users and API/AWS customers in the coming days. Vercel Sandbox now supports Cursor Cloud Agents, giving enterprises an alternative execution environment for agentic workflows. Meta introduced ZGateway, a proxy layer for its widely used ZippyDB key-value store that improves admission control and cross-region resilience. GitHub Copilot app published a beginner guide to running multiple agents in parallel. Together, these updates reflect a developer ecosystem increasingly embracing agent-based, infrastructure-aware workflows.

Languages & Frameworks: Cursor Cloud Agents Now Run in Vercel Sandbox

In this subsection, we look at a notable shift in development infrastructure. Vercel has integrated Cursor's Cloud Agents with its Sandbox environment, so agents can run on Vercel's infrastructure instead of Cursor's hosted machines. Cursor manages the agent harness and inference loop, while the execution environment is supplied by the customer via Self-Hosted Machines APIs. This offers developers more control over security and resource usage when cloning repositories, editing code, and running tests.

Cursor Cloud Agents Can Now Run in Vercel Sandbox Vercel 博客

Vercel Sandbox can now host Cursor Cloud Agents, replacing Cursor's own hosted machines. Cursor handles the agent harness and inference loop, while Self-Hosted Machines APIs let customers supply the execution environment. Users can have agents clone repositories, edit files, and run commands and tests inside Vercel Sandbox. The feature requires Cursor Enterprise, giving companies a way to run AI agents in their own controlled infrastructure.

Infrastructure & Data: Meta's ZGateway Proxy for ZippyDB

This subsection focuses on large-scale data infrastructure. Meta Engineering introduces ZGateway, a proxy designed to unify traffic through ZippyDB, Meta's most widely used key-value store. ZippyDB backs product metadata, counters, and configuration, and ZGateway adds admission control, load balancing, cross-region resilience, and richer operations. It provides practical insights for designing stable storage systems at extreme scale.
