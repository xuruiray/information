This subsection covers toolchain updates. Cursor is now available in the AI SDK harness layer Vercel 博客

The AI SDK harness layer now supports Cursor through the official @ai-sdk/harness-cursor adapter, allowing applications to run different coding agents via the same HarnessAgent interface without changing application code. The adapter is built on @ai-sdk/harness-acp.
