Development & Programming Briefing

This edition of Development & Programming tracks the developer tooling that followed a burst of frontier model releases. Anthropic shipped Claude Opus 5.5, and OpenAI soon followed with GPT-6 Sol and GPT-6 Luna, priced at roughly half of their GPT-5.6 equivalents. The LLM command-line ecosystem updated in parallel: llm-anthropic 0.29 adds Claude Opus 5.5 support; llm 0.36 registers the new OpenAI models and lets plugins declare models that cannot handle multi-turn conversation; and a new llm-typesafe plugin connects TypeSafe AI's Jev model. A San Francisco meetup on 14 October will gather developers building on coding agents.

Open Source & Tools: LLM CLI Update

The LLM command-line tool released version 0.36, adding support for OpenAI's GPT-6 Sol and GPT-6 Luna. Model plugins can now declare that a model only accepts single-turn prompts; LLM raises an error when such models receive assistant or tool history, and llm chat rejects them before starting a session.

llm 0.36 Adds Support for GPT-6 Sol and GPT-6 Luna Simon Willison

llm 0.36 registers two new OpenAI models, gpt-6-sol for GPT-6 Sol and gpt-6-luna for GPT-6 Luna. Model plugins can now declare supports_conversation = False for models that only accept single-turn prompts; LLM raises ConversationNotSupported when such models receive assistant or tool history, and llm chat rejects them before starting a session.
