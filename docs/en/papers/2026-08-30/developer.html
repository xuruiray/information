Development & Programming Briefing

Open Source & Tools Briefing

In Open Source & Tools, security concerns take the spotlight as OCaml projects face rapid exploit attempts. Tencent debuts Hy4, an open-weights LLM. Maintainers of OpenClaw, GitHub's fastest-growing project, share their insights. Vercel's dashboard now enables building and deploying eve agents.

Just a rumour of a bug is enough to find a security exploit these days Simon Willison

Anil Madhavapeddy, professor of computer science at Cambridge and core maintainer of the OCaml compiler, reports that security issues in OCaml projects are seeing attempted exploits within minutes of patches being shared for discussion. This highlights the rapid weaponization of bugs in the open-source ecosystem.

Read more → Introducing Hy4 Preview Simon Willison

Tencent introduces Hy4 Preview, a new open-weight text-input LLM with 770B total parameters, 49B active parameters, a 1M token context window, and 1.56TB on Hugging Face. This marks a significant size increase from July's Hy3, demonstrating fast iteration in the open-source AI space.

OpenClaw is the fastest-growing project in GitHub history. Peter Steinberger and several maintainers share what they learned in the project's first six months, covering building, community, and security challenges, offering insights for open-source maintainers.

Infrastructure & Data Briefing

In Infrastructure & Data, Vercel integrates Claude Managed Agents with Chat SDK, security researchers challenge Claude Code's Auto Mode, and Tencent's Hy4 Preview becomes available on AI Gateway.

Run Claude Managed Agents with Chat SDK Vercel 博客

You can now run Claude Managed Agents with Chat SDK. The agent loop is handled server-side, including the model, tools, session state, and sandboxed web research. This enables building a Slack research bot with one persistent session per thread and streamed briefs with sources.

Read more → Breaking Claude Code Opus 5 Auto Mode Simon Willison

Anthropic has made Claude Code's auto mode the default, trusting it to protect coding agents from prompt injection attacks. But Johann Rehberger, a leading prompt injection researcher, has demonstrated a bypass, challenging the safety claims and highlighting ongoing AI security risks.

Read more → Hy4 Preview now available on AI Gateway Vercel 博客

Hy4 Preview from Tencent is now available on AI Gateway. It is an open-source Mixture-of-Experts model with 770B total parameters (49B active per token) and a 1M token context, aimed at long-horizon coding, document analysis, game development, and scientific reasoning. Use the model ID tencent/hy4-preview.
