Inside the Vercel intern experience Vercel 博客

Vercel explains its internship program, where interns operate as core engineering team members from day one, shipping real products to users. A recent cohort spent four intense months at the San Francisco headquarters learning by delivering to users.

Google's Gemini 3.7 Flash is now available on Vercel AI Gateway at 50% off until December 31, 2026. The model improves on prior Flash versions for software engineering and agentic work, resolving issues more reliably and reducing failed agent loops.

Read more → GLM 5.2 free for eve agents through August 27 via Blackbox on AI Gateway Vercel 博客

GLM 5.2, Z.ai's open-weights coding model with a 1M-token context window, is free for eve agents through August 27 via Blackbox AI on AI Gateway. New eve agents come with GLM 5.2 as default.

Read more → One-click upgrade for deprecated Node.js versions Vercel 博客

Team owners and members can now upgrade all projects on Node.js 20 or earlier to Node.js 24 with one click from the Vercel Dashboard. Project settings are updated; package.json overrides require manual changes, and existing deployments are unaffected.

sqlite-utils 4.2 improves transform() edge cases, llm-gemini 0.33 supports Gemini 3.7 Flash, alchemy-utils boosts DuckDB/CSV performance, and GitHub's Secure Open Source Fund shares AI-era security lessons.

sqlite-utils 4.2 Simon Willison

sqlite-utils 4.2 is out with major improvements to table.transform(), which performs complex alter operations by creating a fresh table, copying data, then swapping. It now preserves more edge-case schema definitions, including check constraints.

Read more → llm-gemini 0.33 Simon Willison

llm-gemini 0.33 adds support for today's Gemini 3.7 Flash, plus gemini-3.6-flash, gemini-3.5-flash-lite, and two embedding models, with compatibility upgrades for LLM 0.32.

Read more → alchemy-utils 0.1a1 Simon Willison

alchemy-utils 0.1a1 is released with notable performance boosts for DuckDB exports and CSV imports, improving throughput on larger datasets. Useful for developers who frequently move data between storage and conversion formats.
