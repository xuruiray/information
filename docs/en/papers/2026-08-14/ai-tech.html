Frontier Models

This subsection covers frontier LLM research, including dynamic governance of multi-agent systems, automated process diagram engineering, a new benchmark for algorithmic trading, diffusion-based lossless compression, and weightless fine-tuning for personalization. These advance system collaboration, engineering applications, and model efficiency.

Dynamic Governance of Multi-LLM Agent Systems for Collaborative Conversational Outcomes arXiv 人工智能

When two AI agents with opposing objectives interact across multiple turns, the lack of a shared goal function leads not to competition but collapse: the visitor capitulates, the site agent stops varying its approach, and the conversation ends without achieving either side's goal. This highlights a critical failure mode for multi-agent systems.

Read more → LLMs in Process Diagram Engineering: From Optimal PFDs to Validated P&IDs arXiv 人工智能

This study explores using large language models to automate the creation of process flow diagrams (PFD) and their conversion to piping and instrumentation diagrams (P&ID), which are currently largely manual. Automation could save time and deliver financial benefits.

Read more → Backtrader-Bench: Benchmarking LLM Agents on Algorithmic Trading with Self-Generated MCQs arXiv 计算语言学

A new benchmark evaluates large language model coding agents in algorithmic trading through self-generated multiple-choice questions and complementary pipelines, reducing data contamination risks and validating backtest outputs. This provides a more robust evaluation for financial AI applications.

Read more → Diffuse to Compress: Leveraging Diffusion LMs for Lossless Compression arXiv 计算语言学

The study uses diffusion language models for lossless text compression to address growing storage pressure from digital data, including plain text, code, and XML, offering a new approach beyond current neural language model-based methods. This could significantly reduce storage costs for large text corpora.

Read more → Weightless Fine-Tuning: Personalizing LLMs via Logit-Space Transport arXiv 机器学习

A training-free method called Weightless Fine-Tuning adapts large language models to target distributions via logit-space transport, dramatically cutting costs for per-user storage and retraining in personalization. It eliminates the need for separate weight access and optimization for each author. This makes personalization more accessible.

Research & Governance

This subsection brings together research on multi-agent safety, recovery after model unlearning, constraint loss under context compaction, robustness of quantized Mixture-of-Experts, and annotation-free sign language recognition, addressing AI trustworthiness and fairness.

Anthropic set AI agents loose on the same task. They started a turf war. TechCrunch AI

Anthropic researchers found that multiple AI agents can clash, collude, and coordinate in unexpected ways when working on the same task, raising questions about whether current safety tests capture the risks of multi-agent systems.

Read more → Measure, Don't Optimize: Forecasting Recovery in LLM Unlearning arXiv 计算语言学

White-box studies show large language models can retain latent traces of target knowledge after unlearning, even when the knowledge is no longer expressed. Existing audits are limited to one-off diagnostics; this research explores whether residual signals can predict future recovery. This has implications for privacy and model correction.

Read more → Lost in Compaction: Evaluating Side-Constraint Loss under Context Compaction arXiv 计算语言学

When context windows are under pressure, large language model systems compact prior context. This research identifies a class of user-issued "session constraints" — such as "do not delete any emails until I confirm" — and evaluates how compaction causes these constraints to be lost.

Read more → Detecting a Route Flip Is Easier Than Knowing Whether to Fix It: Causal Route-Mediated Damage in Quantized Mixture-of-Experts arXiv 人工智能

Top-k Mixture-of-Experts routing is discontinuous, so numerical disturbances like 4-bit KV-cache quantization can flip which experts fire. This study supplies a causal analysis to assess whether such damage needs fixing. It helps deployment decisions for MoE models.

Read more → Gloss-Free Representation Learning for Cross-Dataset Sign Spotting arXiv 计算语言学

Sign-language research is often limited by the cost of dense labels. This study uses weak supervision from broadcast news, pairing continuous signing with transcripts, to explore gloss-free representation learning for cross-dataset sign spotting. It offers a practical path for low-resource sign languages.
