SQLite compressed text-history prototypes Simon Willison

A developer proposes a new approach for storing revision history in relational databases: place the full text of every older version into a JSON array and compress the whole thing with zlib or zstd. The prototype suggests this can compress remarkably well, opening a new direction for text-history storage in SQLite.

Security research project OpenClaw found that an Australian gym-booking website API performs zero authorization checks when canceling other people's reservations. The API has no permission checks at all. In a live test, the researcher canceled the reservation of the person in waitlist position #1, moving from #4 to #3 and exposing a serious access-control flaw.

Auto mode is now the default in Claude Code for Pro, Max, and Team plans Simon Willison

Anthropic says that starting August 14, Auto mode will be the default for new Claude Code sessions on Pro, Max, and Team plans, reducing manual switching. The capability was highlighted during an AI-focused fireside chat, underscoring the company's confidence in automated coding. The change directly affects many daily developer workflows.

Read more → Moonlight & Mayhem (Raccoon Heist by Codex + GPT-5.6 Sol Ultra) Simon Willison

After using Claude Fable 5 to build a complete game in one shot, the author gave the same prompt to Codex Desktop running GPT-5.6 Sol Ultra, testing one-shot game generation across models. Both attempts produced working games from a single premise. The result highlights rapid progress in full-project generation by large language models.

Read more → GitHub Models is now retired Simon Willison

GitHub Models has completed its scheduled retirement. Developers may encounter service-unavailable notices in GitHub Actions; the once-offered model trial and integration service is gone, so users must move to alternatives. The retirement follows a brownout period that interrupted existing automation. Teams should migrate any workflows that depended on GitHub Models to other providers or gateways.

A newly assembled timeline maps the OpenAI accidental attack on Hugging Face, highlighting May 7, when OpenAI started a training run for an experimental, unreleased model, possibly linked to the later outage. The incident continues to spark community discussion. Developers can learn how an infrastructure accident cascades.
