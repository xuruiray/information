Lead Story
Anthropic releases Claude Sonnet 5.5, faster and up to 30% cheaper

Anthropic released Claude Sonnet 5.5, which the company says runs more than 30% faster and costs up to 30% less for most work, priced the same as Sonnet 5 while appearing to beat it on every benchmark. The model is already available on Vercel's AI Gateway and drew heavy discussion on Hacker News. Simon Willison notes it suffers from the same "max" thinking-effort bug as Opus 5.5.

The paper presents ScopeBench, a benchmark evaluating whether autonomous agents preserve client engagement boundaries during web application and network penetration testing. Existing offensive-security benchmarks measure hacking capability, but as they saturate, boundary control becomes a key deployment barrier. The work focuses on agent behavior under goal pressure. arXiv 人工智能 HybridInfer: Thermal-Aware Reinforcement-Learning Tier Routing for On-Device, Edge, and Cloud LLM Inference HybridInfer uses reinforcement learning to route LLM inference among on-device, edge, and cloud tiers. On-device small models keep data local and avoid per-query cost, but the paper finds sustained inference on flagship devices faces sharper thermal constraints.
