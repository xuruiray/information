Frontier Models: New Benchmarks and Agent Breakthroughs

This subsection covers new evaluation benchmarks and agent capabilities. JudgeArena presents a unified, reproducible LLM-as-a-judge framework, while OncoTriad-QA advances pan-cancer multimodal reasoning. Beyond the Hivemind tackles output homogeneity with meta-persona anchoring. HyperAgent uses tool-schema hypergraphs for improved planning, and VeriTrace expands the agentic action space via human-like temporal exploration, pushing performance in hardware design automation.

JudgeArena: A Unified Framework for Reproducible LLM-Judge Evaluation arXiv 计算语言学

LLM-as-a-judge evaluation has become a dominant paradigm for ranking language models, yet most benchmarks ship their own code, hardcode a closed-model judge, and support a single protocol. JudgeArena introduces a unified framework that decouples design choices, aiming to make judge-based evaluations more reproducible, comparable, and suitable for studying how design choices affect outcomes.

Read more → OncoTriad-QA: A Patient-Level Radiology-Pathology-Genomics Benchmark for Pan-Cancer Reasoning arXiv 计算语言学

Cancer diagnosis requires integrating evidence from radiology, pathology, genomics, and clinical metadata, but most medical LLM and VLM benchmarks focus on isolated modalities. OncoTriad-QA introduces a patient-level, pan-cancer reasoning benchmark that captures cross-modal dependencies, providing a more holistic evaluation for medical AI in complex diagnostic settings.

Read more → Beyond the Hivemind: Escaping LLM Homogeneity via Meta-Persona Anchoring and Sequential Temperature Scaling arXiv 人工智能

Recent studies reveal an 'Artificial Hivemind' effect in LLMs that pushes models to converge on a narrow, homogenized consensus even for open questions. Inter-response similarity reaches roughly 0.80–0.90. The authors propose meta-persona anchoring and sequential temperature scaling to escape this semantic collapse, enhancing output diversity while maintaining quality.

Read more → HyperAgent: Planning and Acting over Tool-Schema Hypergraphs for Tool-Use LLM Agents arXiv 人工智能

LLM agents increasingly depend on external tools to complete real-world tasks, but reliable tool-use planning is hampered by implicit reasoning and evolving environments. HyperAgent represents tool schemas as a hypergraph and performs planning over it, allowing agents to model relationships among tools and adapt execution more effectively in complex, dynamic settings.

Read more → VeriTrace: Human-Like Temporal Exploration Completes Agentic Action Space arXiv 人工智能

State-of-the-art multi-agent systems for Verilog RTL generation plateau at about 95% accuracy on standard benchmarks. VeriTrace traces this ceiling to an incomplete debugging action space: existing systems restrict which signals agents can inspect and which time windows to explore. It proposes human-like temporal exploration to complete the action space and push performance higher.

Research & Governance: Evaluation Reliability and Audits

This subsection highlights evaluation reliability and safety. BBOWP-Bench benchmarks optimization formulation from natural-language word problems. OpenAI's Privacy Filter is independently evaluated across 42 benchmarks spanning 22 languages. Legal benchmarks are audited for answer-authority decoupling. MemArena offers an ego-centric benchmark for on-device memory assistants, and Stuck on "A" diagnoses interface injury in attention-to-KDA linearization.

BBOWP-Bench: Evaluating LLMs on Black-Box Optimization Word Problems arXiv 计算语言学

The formulation of an optimization problem strongly affects solution quality, yet good formulations often require substantial expertise. Recent studies explore automatically deriving optimization problems from natural-language descriptions, but benchmarks are limited. BBOWP-Bench provides a dedicated evaluation suite for black-box optimization word problems, testing how well LLMs can turn text into well-posed optimization models.

Read more → Stuck on "A": Diagnosing and Repairing Interface Injury in Attention-to-KDA Linearization of a 0.6B Language Model arXiv 计算语言学

This work converts 21 of 28 full-attention layers in Qwen3-0.6B-Base into KDA linear-attention layers on a single consumer-grade GPU, then asks what exactly the conversion breaks. Hidden-state alignment and end-to-end KL distillation drive the student model, and the authors diagnose and repair 'interface injury' in the attention-to-KDA linearization process.

Read more → MemArena: An Ego-Centric Benchmark for On-Device Agentic Personal Memory Assistants at Scale arXiv 计算语言学

Edge-deployed personal memory assistants must privately handle interpersonal conversations on-device with open-weight models. Existing memory benchmarks often under-test the combination of activity-dense interaction, ego-centric perspective, and coherent multi-session worlds. MemArena fills these gaps with a large-scale, ego-centric benchmark for on-device agentic personal memory assistants.

Read more → Knowing the Form, Not the Function: Automatically Auditing Answer--Authority Decoupling in Legal Benchmarks arXiv 计算语言学

Legal benchmarks typically score final answers even when models also state legal authority. This study tests whether answer correctness can serve as a proxy for authority grounding. Under ordinary reasoning prompts that do not request statutory citations, four LLMs spontaneously produced authority markers across 238 tasks, highlighting a form-function gap and motivating automatic auditing.

Read more → Evaluating OpenAI's Privacy Filter: Cross-Lingual, Cross-Domain PII Detection Across 42 Benchmarks arXiv 计算语言学

This first independent systematic evaluation of OpenAI's Privacy Filter (OPF), a 1.5B-parameter PII detector, spans 42 synthetic benchmarks in 22 languages and 5 domains. Zero-shot, OPF achieves F1=0.855 on AI4Privacy and 0.464 on SPY medical, outperforming Presidio, while results point to meaningful cross-domain gaps.
