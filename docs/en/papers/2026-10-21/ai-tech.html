Frontier Models: Agent Training, Procedural Memory and Transformer Inference Dynamics

Five studies focus on agent capabilities and model internals: Navalia improves cross-document evidence integration and multistep numerical reasoning through verifiable task synthesis and long-horizon post-training; industrial agentic AI analyzes barriers—dynamic environments, physical constraints and reliability requirements—as LLM agents move from predefined workflows to autonomous planning and execution; AtomSD injects reusable procedural knowledge via procedural atom-guided self-distillation; SPEM organizes skills with structure-aware procedural memory to avoid token and runtime overhead and lost dependency information from full loading and flat retrieval; and another study treats ordered layer-state trajectories as an empirical process to test whether layer order defines measurable computation.

Navalia: Advancing Cowork Agents through Verifiable Task Synthesis and Long-Horizon Post-Training arXiv 人工智能

The paper introduces Navalia, a method that combines verifiable task synthesis with long-horizon post-training to improve LLM cowork agents on cross-document evidence integration and multistep numerical reasoning in financial analysis.

Read more → Industrial Agentic AI: LLM-Driven New-Generation Agents for Smart Manufacturing arXiv 人工智能

The paper examines how LLM-driven agents move beyond predefined workflows toward autonomous planning and execution in smart manufacturing, while highlighting dynamic environments, physical constraints and reliability requirements as deployment barriers.

Read more → AtomSD: Procedural Atom-Guided Self-Distillation for LLM Agents arXiv 计算语言学

AtomSD uses procedural atom-guided self-distillation to give LLM agents reusable procedural knowledge, aiming to improve flexible action and reuse across interactions in complex tasks.

Read more → SPEM: Structure-Aware Procedural Memory for Efficient Skill Use in LLM Agents arXiv 人工智能

SPEM introduces structure-aware procedural memory for LLM agents, organizing reusable skills to avoid full skill loading and flat retrieval that incur token and runtime overhead and ignore dependencies.

Read more → High-dimensional layer-state trajectories reveal the internal dynamics of transformer inference arXiv 机器学习

The study treats ordered layer-state trajectories as an empirical process and tests whether layer order defines measurable computation, offering a dynamic view of how transformer inference unfolds.

Research and Governance: Math Reasoning Evaluation, Safety Bill and Clinical Trustworthiness

Research and governance items include MAMath-Bench, which evaluates multimodal multi-agent mathematical reasoning with process-aware and robust assessment beyond answer correctness; Anthropic’s proposed AI safety bill that could block a model if 50 or more people could be killed, with TechCrunch reporting that federal agencies would need a judge’s permission to block a release; a paper asking whether multi-agent collaboration reduces hallucination in clinical tasks and separating performance gains from trustworthiness; CERTA’s decision-level statistical certificate for determining when a quantized clinical model can substitute for its BF16 reference and escalating uncertified decisions; and WaveCommitments’ private and verifiable mechanisms for speech-agent marketplaces.

MAMath-Bench: Process-Aware and Robust Evaluation of Multimodal Multi-Agent Mathematical Reasoning arXiv 人工智能

MAMath-Bench evaluates multimodal multi-agent mathematical reasoning with attention to process-aware and robust assessment, requiring not only correct answers but coherent, verifiable reasoning processes.

Read more → Anthropic pitches AI safety bill that may block a model if 50+ people could be killed TechCrunch AI

Anthropic is pitching an AI safety bill that could block a model if 50 or more people could be killed, but TechCrunch reports federal agencies would need a judge’s permission to block a release.

Read more → Does Multi-Agent Collaboration Reduce Hallucination in Clinical Tasks? arXiv 人工智能

The paper separates performance gains of multi-agent LLM systems on clinical tasks from trustworthiness, asking whether collaboration reduces hallucination and what that means for clinicians acting on stated reasoning.

Read more → Do We Need the Largest LLMs for Every Clinical Decision? arXiv 计算语言学

CERTA introduces a decision-level statistical certificate to determine when a quantized clinical model can substitute for its BF16 reference and escalate uncertified decisions, aiming to support local deployment.

Read more → WaveCommitments: Private and Verifiable Speech-Agent Marketplaces arXiv 计算语言学

WaveCommitments proposes private and verifiable mechanisms for speech-agent marketplaces, letting sellers submit assets for evaluation without revealing them and buyers price assets they cannot directly test.
