Auto mode is now the default in Claude Code for Pro, Max, and Team plans

Anthropic will make Auto mode the default for new sessions in Claude Code for Pro, Max, and Team plans starting August 14. The change is set to boost developer productivity and mainstream autonomous AI programming.
