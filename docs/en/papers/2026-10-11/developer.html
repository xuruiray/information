How Rillet ships 3× faster with AI agents on Vercel Vercel 博客

Rillet tripled its shipping rate in three months with eve agents deployed on Vercel. A two-person team closed more than 800 Linear tickets in its first four months and can push customer-requested changes to production in as little as two hours. Builder access is handled via Enterprise Managed Users, SSO, and Directory Sync, with models available through AI Gateway.

Read more → Deno is joining Cloudflare Simon Willison

The Deno team released celld in August, its open source implementation of Cloudflare Workers' Durable Objects pattern. Cloudflare is now acquiring Deno outright, aiming to build on celld to make self-hosting workerd a first-class supported way to build and run Worker-based apps.

Read more → Quoting Matthew Green Simon Willison

Cryptographer Matthew Green says he puts a 1% chance on us living in Minicrypt and a 15% chance that we functionally lose confidence in existing public-key encryption algorithms. He points to the mismatch between the speed of AI-driven surprises and the speed at which humans can respond.

Read more → Quoting Carson Gross Simon Willison

Carson Gross argues that computer programming is fundamentally about two things: problem-solving with computers, and learning to control complexity while solving those problems. He finds it hard to imagine a future where knowing how to do both is less valuable than it is today.

A new feature for my blog, built using my voice Simon Willison

Simon Willison shipped a Newsletters page for his blog, indexing both his free weekly Substack and his monthly sponsors-only updates. He built the feature almost entirely with his voice, chatting to his laptop while cooking, using Codex voice mode in the ChatGPT desktop app.

Read more → ttok 0.4 Simon Willison

ttok is a CLI token-counting tool built on OpenAI's open source tiktoken library. Version 0.4 fixes a Click warning, updates CI, and adds a --list-models command. It runs via uvx, so you can count tokens with a command such as cat file.txt | uvx ttok.

Read more → Dwarf Fortress uses version control now Simon Willison
