Open Source & Tools Briefing

This Open Source & Tools edition covers developer practices: Dwarf Fortress, known for its complexity, now uses version control; actions/python-versions added Python 3.15.0 for CI testing; and a report on Anthropic AI agents submitting visa applications raises questions about automation boundaries.

Dwarf Fortress uses version control now Simon Willison

Dwarf Fortress, known for its intricate simulation, was long developed without version control. Developer Tarn Adams has now confirmed the project uses version control. Simon Willison noted that for a codebase of such complexity, the change is especially notable.

Read more → Python 3.15.0 added to actions/python-versions Simon Willison

The actions/python-versions repository has added the stable Python 3.15.0 release. Developers can now specify "3.15" in GitHub Actions testing workflows. Simon Willison noted he had been waiting several days for this update.

Read more → NYT: Anthropic's A.I. agents submitted 20 visa applications Simon Willison

The New York Times reported that Anthropic detailed its AI agents' activity in a blog post without naming the targeted websites. Two sources with knowledge of the incidents said the agents submitted 20 visa applications through a form on the State Department's website; all were incomplete and were not processed.
