Frontier Models: Decomposing Agent Competence, Memory, and Spatial Reasoning

The five papers in this group decompose task and interface competence in agentic training; introduce SpatialCraft, which evolves procedural intelligence for spatial-reasoning agents from experience and skills; present MGMem, an efficient, deterministic, and provenance-preserving long-horizon memory framework; examine whether LLMs exhibit extraneous cognitive load from how task information is presented; and propose REI to learn ideation from repository evolution.

Learning What vs. Learning How: Decomposing Task and Interface Competence in Agentic Training arXiv 人工智能

The paper separates task knowledge from interface competence in agentic training, arguing that a model can know a task yet fail under a given harness of prompts, action formats, and feedback loops.

Read more → SpatialCraft: Evolving Procedural Intelligence from Experience and Skills for Spatial Reasoning Agents arXiv 人工智能

SpatialCraft trains spatial reasoning agents to evolve procedural intelligence from experience and skills, coordinating external tools such as 3D reconstruction, segmentation, and geometric computation.

Read more → MGMem: An Efficient, Deterministic, and Provenance-Preserving Framework for Long-Horizon Agent Memory arXiv 计算语言学

MGMem is an efficient, deterministic, and provenance-preserving memory framework for long-horizon agents, avoiding the high cost of repeatedly invoking generative models to rewrite interaction history.

Read more → Extraneous Cognitive Load in Large Language Models arXiv 计算语言学

Borrowing from Cognitive Load Theory, the paper examines whether large language models exhibit extraneous cognitive load, where how task information is presented alone affects problem-solving performance.

Read more → REI: Learning Ideation from Repository Evolution arXiv 机器学习

REI learns ideation from repository evolution to ease the bottleneck in automated AI experimentation, where useful ideas are sparse and validation is costly.

Research and Governance: Deepfakes, Interactive Charts, and Agent Failure Attribution

The five papers in this group release MOZAIC, an audio-video deepfake benchmark with four-way paired labels separating fake faces, voices, or both; propose an interactive chart-to-code benchmark for multimodal LLMs; evaluate and calibrate 25 open-weight multilingual decision models across 17 tasks in 14 languages; attribute failures of vision-language agents using interactive 2D environments; and pilot-evaluate how language models answer when reference material covers only part of a question.

MOZAIC: An Audio-Video Deepfake Benchmark for Telling What Is Fake arXiv 人工智能

MOZAIC is a paired audio-video deepfake benchmark with four-way labels that separates fake faces, voices, or both, helping reveal whether detectors rely on images, speech, or encoding traces.

Read more → Beyond Static Charts: Benchmarking Interactive Chart-to-Code Generation for MLLMs arXiv 人工智能

The paper introduces a benchmark for interactive chart-to-code generation by multimodal LLMs, filling a gap left by evaluations that cover only static charts and ignore interactive data exploration.

Read more → Lost in Translation, Not in Confidence: Benchmarking and Calibrating Multilingual Decision Models arXiv 计算语言学

The study evaluates 25 open-weight decision models across 17 tasks in 14 languages, probing how multilingual routers and guardrails perform and calibrate outside English.

Read more → Attributing Agentic Failure in Reasoning Vision-Language Models with Interactive 2D Environments arXiv 机器学习

Using interactive 2D environments, the paper attributes failures of reasoning vision-language agents to distinct causes such as misreading the environment, misunderstanding components, wrong ordering, and failure to recover.

Read more → When the Knowledge Runs Out: A Part-Level Pilot Evaluation of How Language Models Handle Partially Covered Questions arXiv 计算语言学

This pilot evaluation examines how language models answer when reference material covers only part of a question, noting that prior evaluations often treat partially sufficient context as simply insufficient.
