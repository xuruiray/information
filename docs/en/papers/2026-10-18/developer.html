Open Source & Tools: File editing, chirp-based game, and browser emulator

Simon Willison released web-edit 0.1a2, a tiny web app for browsing and editing files in a folder, adding copy-to-clipboard support for text and image data. He also tested a two-player competitive Pong game running as static HTML on two phones, with game state sent over chirps received by the microphone, and reports that it works. GitHub Engineering explains how a shared organization used native GitHub features to automate reviews of outside collaborator access and archive stale repositories; the open source esp32sim project provides a browser-based ESP32 emulator that executes firmware without physical hardware.
