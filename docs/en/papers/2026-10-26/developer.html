Open Source & Tools: Vercel spend management, MCP feedback and image tools

The Vercel CLI adds the vercel budgets command for viewing current spend and active budgets and setting or removing on-demand budgets; Vercel MCP adds a submit_feedback tool for submitting bugs, friction and feature requests in plain language; Simon Willison released Seam Cutter and Quick Study for seam-cut image cropping and rapid canvas-based photo painting.

Vercel CLI adds Spend Management Vercel 博客

The Vercel CLI now lets teams view current spend and active budgets and set or remove on-demand budgets via the vercel budgets command; setting a budget alone does not stop usage.

Read more → Send feedback from the Vercel MCP Vercel 博客

Vercel MCP now includes a submit_feedback tool that lets agents send bug reports, friction reports and feature requests to Vercel in plain language, with structured context.

Read more → Seam Cutter Simon Willison

Simon Willison released Seam Cutter, a tool that makes a horizontal or vertical cut across an image and slides the two sides to crop out a middle section, useful for stitching screenshots.

Read more → Quick Study Simon Willison

Quick Study is a tool that opens a photo and rapidly paints a version of it using a canvas element and simulated paintbrush, employing Sobel edge detection.

Infrastructure & Data: Agent production access, build cache and managed keys

Vercel outlines the permission design for its agent accessing production systems, noting that requests like “fix this deployment” do not specify needed actions; deployment summaries now show build cache size and proximity to the build machine limit; Vercel Connect can create a separate restricted Stripe API key for each agent or task.

How Vercel Agent accesses production safely Vercel 博客

Vercel outlines how its agent accesses production systems safely, noting that a request like “fix this deployment” does not specify needed actions, while broad access risks unrelated resources.

Read more → Deployments now show build cache size Vercel 博客

Vercel deployment summaries now show the build cache size saved per deployment and how close it is to the build machine limit; the CLI and REST API expose the same data.

Read more → Vercel Connect adds managed Stripe API keys Vercel 博客

Vercel Connect can now create a separate restricted Stripe API key for each agent or task, letting users choose permissions when creating a connector; existing methods remain unchanged.
