Infrastructure & Data Briefing

Infrastructure updates: Vercel Chat SDK supports Claude Managed Agents for simplified server-side ops; a researcher breaks Claude Code Opus 5 auto mode, questioning prompt injection defenses; Tencent's Hy4 Preview MoE model arrives on AI Gateway with a 1M context option.

Run Claude Managed Agents with Chat SDK Vercel 博客

Vercel's Chat SDK now supports Claude Managed Agents, which handle the agent loop server-side including model, tools, session state, and sandboxed web research. Developers can ship Slack research bots with persistent per-thread sessions and streamed briefs with sources.

Read more → Breaking Claude Code Opus 5 Auto Mode Simon Willison

Anthropic relies heavily on Claude Code's auto mode to protect coding agents from prompt injection and made it default. Johann Rehberger, a leading prompt injection researcher, demonstrates a break, calling the mode's effectiveness into question.

Read more → Hy4 Preview now available on AI Gateway Vercel 博客

Tencent's open-source Hy4 Preview model is now on AI Gateway. It's a Mixture-of-Experts model with 770B total parameters, 49B active per token, and a 1M token context window, targeting long-horizon coding, document analysis, game development, and scientific reasoning.
