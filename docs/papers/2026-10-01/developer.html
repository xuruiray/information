开发与编程总结

今日开发与编程版以 Vercel 平台更新为主：Vercel Agent 支持从 npm 与自定义注册表安装私有依赖，凭据以共享环境变量托管；AI Gateway 接入 Browserbase 的 Search 与 Fetch 工具，为模型补足联网检索与页面抓取能力；原 Edge Requests 用量指标更名为 CDN Requests，定价、限额与计量方式均不变。此外收录一则来自开发者博客的博物馆参观随笔。

语言与框架小版总结

Vercel Agent 现可从 npm 及自定义注册表安装私有依赖 Vercel 博客

Vercel Agent 现可安装来自 npm 与自定义注册表的私有依赖，凭据以共享环境变量的形式存储在 Vercel 上。在 Agent 会话中运行的 npm、pnpm 与经典 Yarn 的认证方式与 Vercel 构建一致；用户可在 Development 或 Preview 环境添加共享环境变量，托管于 npm 的私有包使用 NPM_TOKEN。

阅读全文 → AI Gateway 新增 Browserbase 搜索与抓取工具 Vercel 博客

Browserbase 的 Search 与 Fetch 工具现已通过 Vercel AI Gateway 提供：模型可获取最新信息、查找相关页面并抓取页面内容，并与已有的 AI SDK 和 Vercel Marketplace 集成并存。用户可用一个 API 密钥跨模型供应商使用这些工具，为模型加入网页搜索与页面取回能力。

阅读全文 → Vercel 将 Edge Requests 用量指标更名为 CDN Requests Vercel 博客

Vercel 宣布把此前名为 Edge Requests 的用量指标更名为 CDN Requests。此次仅为名称调整：定价、限额与计量方式均不变。新名称将出现在用量仪表盘、Observability 事件图表、用量通知与发票明细中，以体现这些请求由其 CDN 提供服务。
