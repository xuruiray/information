开发与编程日报：Datasette 图表插件钩子、SQLite 远程复制工具与 Convex skills 争议

本期开发与编程版聚焦 Datasette 生态的插件更新、SQLite 的数据库远程复制工具，以及围绕 Convex skills 将用户应用创意发送至远程服务器的争议。Simon Willison 发布 datasette-charts 0.4a0，新增让其他插件定义图表类型的插件钩子，并借助 Claude Opus 5.5 构建实验插件验证该钩子；datasette-mcp 0.4 修复与 Datasette 1.0a44 的兼容性；此前的 datasette-charts 0.3a0 增加图表标注功能。基础设施方面，sqlite3_rsync 作为 SQLite 的数据库远程复制工具，于 2024 年 3.47.0 作为实验特性加入、2025 年 3.50.0 得到增强。此外，Hacker News 上一则关于 Convex skills 未经告知将用户应用创意发送至远程服务器的 GitHub issue 获得 289 分和 92 条评论。

Datasette 插件更新：图表自定义钩子与 MCP 兼容性修复

Simon Willison 发布 datasette-charts 0.4a0，新增插件钩子让其他插件定义图表类型；作者用 Claude Opus 5.5 构建实验插件测试该钩子，并修复设计中的摩擦点。datasette-mcp 0.4 发布，主要修复与 Datasette 1.0a44 的兼容性问题。此前的 datasette-charts 0.3a0 新增图表标注功能，可在图表上添加线条、阴影区域、标签或三者组合，并可在 Datasette Lite 中通过图表构建器调整。
