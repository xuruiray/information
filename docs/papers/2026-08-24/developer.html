开源与工具版总结

llm 命令行工具发布 0.33 版本，升级 OpenAI Python 库并新增嵌入参数；llm-openrouter 0.7 兼容 LLM 0.32，支持推理痕迹与服务器端工具。另有报道称 Anthropic 最强 AI 模型在吸引用户方面不及更便宜的工具，反映开源与商业模型的竞争格局。

命令行工具 llm 发布 0.33 版本，升级 OpenAI 库并新增嵌入选项 Simon Willison

llm 0.33 升级到 OpenAI Python 库 3.x，并将 HTTP 客户端从 httpx 切换为 httpx2，同时修复了导致全新安装失败的依赖问题。llm embed 与 embed-multi 新增 --key 参数，Python 的 EmbeddingModel.embed() 等接口同步更新。

阅读全文 → llm-openrouter 0.7 发布，支持推理痕迹与服务器端工具 Simon Willison

llm-openrouter 0.7 已兼容 LLM 0.32，可显示 OpenRouter 上模型的推理痕迹。模型改用 OpenRouter 的 Responses API，并新增 Shell、WebFetch、WebSearch 三个服务器端工具，可通过 -T 等选项启用，适合更复杂的工作流。
