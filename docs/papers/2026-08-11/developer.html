语言与框架：API安全警示

本版块关注语言与框架在实际应用中的安全边界。OpenClaw的案例显示，API若缺乏授权校验，可被轻易滥用。开发者应将访问控制视为框架设计的基础，而不是事后补丁。

OpenClaw 揭示 API 授权漏洞 Simon Willison

安全研究员 OpenClaw 在测试一个澳大利亚健身房预订网站时发现，其 API 在取消他人预订方面完全没有授权检查。他实际测试了候补名单第一位用户的预订取消操作，并获得成功，这展示出 API 访问控制的严重缺失。

开源与工具：模型发布与开发者工具更新

开源生态迎来多项重要更新：Vercel推出可扩展的托管基础镜像；Meta发布Apache 2.0许可的Muse Glimmer模型；GitHub为Java开发者提供Copilot SDK；Cactus推出14MB微型大语言模型Needle2，面向边缘设备。这些进展降低了AI与云原生开发的门槛。

Vercel Sandbox 现基于 Vercel 托管镜像运行 Vercel 博客

Vercel 发布 Vercel 托管镜像（VMI），这是一组带版本号的开源基础镜像，可直接使用或扩展。所有镜像源码均存放在公开的 vercel/sandbox 仓库中。托管镜像取代了已弃用的 Sandbox 运行时；自 Sandbox SDK 第3版起，新沙箱默认使用 vercel/sandbox/universal 镜像。

基础设施与数据

3 条
基础设施与数据：沙箱需要网络边界

本版块聚焦运行时隔离安全。Vercel指出，微虚拟机只能隔离主机访问，若缺少网络边界，沙箱并不完整。在AI智能体愈发能自主读写文件、执行命令的背景下，网络控制成为基础设施安全的关键一环。

没有网络边界的沙箱只是半个沙箱 Vercel 博客

安全运行不受信任的代码，不仅需要将其与宿主机隔离，还要控制其网络访问。随着AI智能体能够自行读取文件、执行命令、安装包和生成程序，这一点愈发重要。微虚拟机可阻止代码访问宿主机或其他工作负载，但仅靠它无法提供完整的隔离。
