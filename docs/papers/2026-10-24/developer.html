开源与工具：Vercel 反馈入口扩展，Quick Study 展示画布重绘

Vercel CLI 新增 feedback 命令，支持通过 --field 提交结构化反馈，并可通过 vercel budgets 查看和管理团队按需预算；Vercel MCP 新增 submit_feedback 工具，让代理以自然语言提交缺陷、使用摩擦和功能请求。Simon Willison 展示了 Quick Study：根据 Claude Opus 5.5 High 提示生成，打开照片后用 canvas 和模拟画笔在数秒内重绘，并使用 Sobel 边缘检测。

Vercel CLI 新增 feedback 命令，可从终端提交反馈 Vercel 博客

Vercel CLI 加入 vercel feedback 命令，开发者可用终端提交缺陷、使用摩擦和功能请求；支持 -f/--field 以 key=value 附加结构化上下文，编码代理也可调用。

阅读全文 → Vercel CLI 新增 Spend Management 预算管理 Vercel 博客

Vercel CLI 现在可通过 vercel budgets 查看和管理团队按需预算，返回当前支出与生效预算；命令支持设置、查看和移除预算，设置预算本身不会停止用量。

阅读全文 → Vercel MCP 新增 submit_feedback 工具，代理可直接提交反馈 Vercel 博客

Vercel MCP 加入 submit_feedback 工具，代理或运行框架可用自然语言向 Vercel 团队发送缺陷、摩擦报告和功能请求，并可附带结构化上下文。

基础设施与数据：Interfaze 规模实践与 Vercel 生产访问、缓存和密钥管理

Interfaze 每月在 Vercel 处理 5000 万次请求，后端使用 Fluid compute，并通过 AI Gateway 将多家模型商放在统一回退层，其模型专注文档处理、OCR、目标检测和语音转文字等任务。Vercel Agent 介绍了安全访问生产系统的权限方案；部署摘要新增构建缓存大小显示，CLI 65.1.0 及以上的 vercel inspect 和 get-deployment REST API 也可查看；Vercel Connect 可为每个代理或任务创建单独的受限 Stripe API 密钥。

Interfaze 如何在 Vercel 上每月处理 5000 万次请求 Vercel 博客

Interfaze 每月在 Vercel 处理 5000 万次请求，后端用 Fluid compute，并通过 AI Gateway 将多家模型商放在统一回退层；其模型专注文档处理、OCR、目标检测和语音转文字等任务。

阅读全文 → Vercel Agent 如何安全访问生产环境 Vercel 博客

Vercel 介绍其 Agent 访问生产系统的权限方案：在代理需要执行“修复部署”等操作时，平衡广泛权限的风险与逐步审批的负担，避免误操作影响无关资源。

阅读全文 → Vercel 部署摘要新增构建缓存大小显示 Vercel 博客

Vercel 部署摘要现在显示每次部署节省的构建缓存大小及其距上限的接近程度；CLI 65.1.0 及以上的 vercel inspect 和 get-deployment REST API 也可查看。

阅读全文 → Vercel Connect 新增托管 Stripe API 密钥 Vercel 博客

Vercel Connect 现可为每个代理或任务创建单独的受限 Stripe API 密钥；创建连接器时可选 Managed API Key，Vercel 会按所选权限在用户账户中生成密钥。
