航天能源与机器人总结

工程、物理与行星科学交叉涌现多项进展：针织材料学会变形，细菌电路具备计算雏形，霍尔效应迎来新形式，火星深处还发现了挑战传统认知的岩浆系统。

哈佛研究人员把针织变成可变形智能面料 ScienceDaily 技术

哈佛研究人员利用弹性纱线与工业针织技术，研制出可自然弯曲并锁定在多种稳定形态的厚实面料，模式切换类似电灯开关。这类智能织物未来有望用于可变形结构、软体机器人和功能性穿戴设备。

阅读全文 → 麻省理工学院将细菌变成活体晶体管 ScienceDaily 技术

麻省理工学院的团队把细菌改造成可拼接的“晶体管”，进而组成能执行计算并传递化学信号的活体电路。研究设想，这类生物计算机未来可能覆盖植物根叶，在检测到环境威胁时自动触发防御机制。

阅读全文 → 科学家发现新型霍尔效应，推翻百年物理假设 ScienceDaily 技术

卡内基梅隆大学科学家发现一种此前未知的霍尔效应形式，推翻了一个世纪以来它只出现在垂直于材料的外部磁场中的假设。新成果或有助于制造更简单、灵敏的电磁传感器。

阅读全文 → 科学家在火星深处发现大规模隐藏岩浆系统 ScienceDaily 技术

地震学证据显示，火星地壳深处存在大规模岩浆系统，熔融岩石可能在数百至数千公里的范围内反复演化和循环。这挑战了只有在地球式板块构造作用下才能形成复杂岩浆活动的传统观点。

科学研究总结

科研领域带来一系列引人入胜的发现：土星南极正在形成巨型十边形大气结构，暗物质探测器记录到难以解释的粒子信号，海鞘提取物改善老年小鼠多项衰老指标，研究人员还直接观测到古菌与细菌的物质交换，可能为复杂生命起源提供线索。

NASA 在土星南极发现巨型十边形大气结构 ScienceDaily 科学

NASA 借助哈勃数据发现，土星南极上空正形成一个巨型十边形大气结构，成为北半球著名六边形的对应物。十边形似乎在近年间才出现并不断增强，科学家将追踪其成因及演化。

阅读全文 → 暗物质探测器捕捉到难以解释的神秘信号 ScienceDaily 科学

LUX-ZEPLIN 暗物质实验捕捉到一起罕见的粒子相互作用，该事件难以用普通背景噪声解释，且出现在可能产生暗物质信号的区域。研究人员并未宣称发现暗物质，但后续数据可能揭示其真正性质。

阅读全文 → 斯坦福发现海鞘中的物质可逆转多项衰老迹象 ScienceDaily 科学

斯坦福大学发现，可食用海鞘中的缩醛磷脂能改善老年小鼠的记忆与学习，增强脑细胞连接，减轻炎症并让毛发更浓密。研究人员认为这类化合物或许能促进脑部再生、保护衰老突触。

阅读全文 → 古“活化石”微生物或揭示复杂生命如何诞生 ScienceDaily 科学

研究人员首次拍到生活在叠层石群落中的阿斯加德古菌与细菌直接相连并交换物质。这种共生关系可能类似数十亿年前促成复杂生命出现的关键合作，为理解真核细胞与生命演化提供新证据。
