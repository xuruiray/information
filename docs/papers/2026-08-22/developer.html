阅读全文 → LLM 0.32.1 发布：修复依赖回退问题 Simon Willison

LLM 命令行工具发布 0.32.1 补丁版本。由于 OpenAI Python 库不再依赖 httpx，而 LLM 此前通过传递依赖隐式使用该库，导致新装环境失效。本次更新通过锁定 openai<3 临时解决，后续 0.33 将彻底切换 HTTP 客户端。
