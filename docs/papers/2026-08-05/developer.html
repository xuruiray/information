LLM 0.32 发布：新增推理轨迹、OpenAI Responses 与服务端工具 Simon Willison

Simon Willison 发布 LLM 0.32，这是项目启动以来最重要的新版本。新版支持可见的推理轨迹、服务端提供商工具、重新设计的内容寻址 SQLite 日志，并可结合 OpenAI Responses API 使用新模型与功能。作者还同时发布了配套的 llm-anthropic 插件更新。

阅读全文 → skills.sh 推出技能包，可一站式共享多个代理技能 Vercel 博客

Vercel 宣布 skills.sh 支持把多个代理技能捆绑为可分享的技术包。用户可通过单一 URL 分发技能集，或与 GitHub 组织共享以统一团队代理在各项目中的行为；技能包可基于社区技能、本地文件夹、压缩包或 GitHub 仓库创建。

阅读全文 → Vercel 优化 ISR 部署：含大量预渲染页面的应用提速最高 33% Vercel 博客

Vercel 针对使用增量静态再生（ISR）的应用优化部署流程，预渲染页面越多，节省越明显。此前每个 ISR 页面都附有路由元数据，部署时需要重复处理；新方案减少了这部分开销，使部署更快。

MiniMax-H3 多模态生成系统推出 MLX 移植版，可在苹果芯片本地运行 Simon Willison

MiniMax 发布 MiniMax-H3，定位为“全模态生成系统”，可接受文本、图像、音频和视频输入，并生成最长 15 秒的含音频视频片段。一个 Python 包将该系统移植到 MLX，使其能在 Apple Silicon 上本地运行。
