Claude Code 2.1.277 起支持 AGENTS.md 项目指令文件 Simon Willison

Claude Code 从 2.1.277 版起，若目录中没有 CLAUDE.md，将自动查找并使用 AGENTS.md 作为项目指令文件。该支持基于即将推出的 Claude Code mods 机制，目前以内置 mod 形式提供，用户未来可自定义项目指令的构建方式。

Z.ai 多模态编码模型 GLM 5.3 FlashX 的高速推理选项上线 AI Gateway，推理速度约每秒 200 tokens，适合编码智能体、工具调用循环以及用户等待输出的交互式应用，调用标识为 zai/glm-5.3-flashx。

阅读全文 → Vercel CLI 支持亚秒级静态产物部署 Vercel 博客

Vercel CLI 现在可以在一秒内把静态产物部署到 Vercel。Vercel 会自动识别符合条件的部署，有效产物将跳过构建步骤并立即返回线上 URL，便于分享原型、发布 HTML 报告或预览编码智能体生成的页面。

阅读全文 → Turbo 构建机器可按单次部署启用 Vercel 博客

Vercel 允许在单个部署上启用 Turbo 构建机器，无需修改项目设置。可通过三种方式操作：在 Git 提交信息中写入 #VERCEL_BUILD_MACHINE=TURBO，使用 vc deploy --turbo（需 CLI 59.20.0 及以上），或在配置中设置 buildMachine。
