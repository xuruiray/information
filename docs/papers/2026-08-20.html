OpenRouter 并入 Stripe，AI 模型调用平台迎整合

OpenRouter 是一个统一访问多家 AI 模型的 API 平台，官方宣布并入支付基础设施公司 Stripe。此前有报道称 Stripe 拟以超过 70 亿美元收购 OpenRouter。此次整合预计将改变 AI 模型的分发与计费方式，也让开发者工具与支付能力更紧密地结合。HN 社区对此讨论热烈。
