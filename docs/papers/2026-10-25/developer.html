开源与工具：Vercel 反馈与预算命令、Roku 迁移 GitLab

Vercel CLI 新增 feedback 反馈命令和 budgets 支出管理命令，Vercel MCP 增加 submit_feedback 工具；Roku 则宣布将开发者仓库从 GitHub 迁至 GitLab。

Vercel CLI 新增 feedback 反馈命令 Vercel 博客

Vercel CLI 加入 vercel feedback，可从终端提交缺陷、使用摩擦和功能请求，并支持用 -f 或 --field 附带结构化上下文；编码代理也可调用。

阅读全文 → Roku 将开发者仓库从 GitHub 迁至 GitLab Hacker News

Roku 宣布把开发者相关代码仓库从 GitHub 迁移到 GitLab；Hacker News 上该消息获得 273 分和 186 条评论。

阅读全文 → Vercel CLI 增加支出管理功能 Vercel 博客

Vercel CLI 新增 vercel budgets，可查看并设置团队的按需预算；设置预算本身不会停止用量，命令行还会返回当前支出和生效预算。

阅读全文 → Vercel MCP 新增 submit_feedback 工具 Vercel 博客

Vercel MCP 加入 submit_feedback，可从代理或运行框架向 Vercel 团队提交缺陷、摩擦报告和功能请求，并允许助手附带结构化上下文。

基础设施与数据：生产规模、代理权限与构建缓存

Interfaze 在 Vercel 上月处理 5000 万次请求，Vercel Agent 说明生产环境权限设计，部署摘要新增构建缓存大小展示，Vercel Connect 支持按代理或任务创建受限的托管 Stripe API 密钥。

Interfaze 在 Vercel 上月处理 5000 万次请求 Vercel 博客

Interfaze 的月度请求量达到 5000 万次，后端运行在 Vercel Fluid compute 上，并通过 AI Gateway 在多个模型供应商之间做回退。

阅读全文 → Vercel Agent 如何安全访问生产环境 Vercel 博客

Vercel 说明其生产环境代理的权限设计：既要避免广泛授权误伤无关资源，也要减少逐步审批带来的操作负担。

阅读全文 → Vercel 部署摘要显示构建缓存大小 Vercel 博客

Vercel 部署摘要现在显示每次部署节省的构建缓存大小，以及距离构建机器上限的余量；同样信息可在 CLI 的 vercel inspect 和 REST API 中查看。

阅读全文 → Vercel Connect 支持托管 Stripe API 密钥 Vercel 博客

Vercel Connect 可为每个代理或任务创建单独的受限 Stripe API 密钥；创建连接时可选择托管密钥方式，并限定所选权限，原有 MCP 和自带密钥方式不变。
