语言与框架：Vercel沙箱可运行Cursor Cloud Agents

本小版块聚焦语言与框架层的开发环境变化。Vercel与Cursor推出集成，让Cursor Cloud Agents可在Vercel Sandbox而非Cursor托管机器上运行，企业用户能够借助Vercel的基础设施执行仓库克隆、编辑和测试等任务，为智能代理提供更灵活的安全边界与弹性资源。

Cursor Cloud Agents现已支持在Vercel沙箱中运行 Vercel 博客

Vercel沙箱现在可以运行Cursor Cloud Agents，替代Cursor托管的执行机器。Cursor负责代理框架与推理循环，通过Self-Hosted Machines API支持外部环境。用户可以在Vercel Sandbox中让代理克隆仓库、编辑文件和执行命令测试。该功能需要Cursor Enterprise计划，意味着企业可在自己管控的基础设施中运行AI代理。
