语言与框架：Node.js 26 LTS 与 fx 适配器更新

Vercel 宣布 Node.js 26 LTS 可用于构建和 Vercel Functions，内置 fetch 默认启用 HTTP/2 并新增 Temporal API；其 AI SDK HarnessAgent 的 fx 适配器改用 libfx，使 harness 与模型请求在应用进程内运行，文件系统与 shell 操作仍留在沙箱。

Vercel 支持用 Node.js 26 LTS 构建和运行 Vercel Functions Vercel 博客

Vercel 宣布，Node.js 26 LTS 现在可用于构建和 Vercel Functions：内置 fetch 默认启用 HTTP/2（Undici 8），可复用连接以降低延迟，并新增不可变 Temporal API。

阅读全文 → Vercel 的 fx 适配器改为在宿主进程运行 HarnessAgent Vercel 博客

AI SDK 的 HarnessAgent 的 fx 适配器改用 TypeScript 库 libfx：harness 与模型请求在应用进程内运行，文件系统与 shell 操作仍隔离在沙箱中，无需再安装 fx 或架设沙箱桥接。

基础设施与数据：AI 爬虫控制、IP 地理定位与 webhook 触发

Vercel Firewall 的 AI Bots 托管规则集可分别记录或拦截 AI 爬虫与 AI 助手；IP 地理定位可对几乎所有请求给出城市级数据、对 90% 流量给出邮编级数据；Vercel Connect 新增 Resend、X、Twilio、Notion 和 Telegram 的 webhook 触发，并代为校验请求、处理心跳与验证挑战。

Vercel Firewall 可分别限制 AI 爬虫与 AI 助手 Vercel 博客

Vercel Firewall 的 AI Bots 托管规则集现可分别记录或拦截 AI 爬虫与 AI 助手请求：爬虫为索引和训练抓取内容，助手响应用户操作或搜索取页，因此可只拦爬虫、放行助手。

阅读全文 → Vercel IP 地理定位精度提升：几乎所有请求都能定位到城市级 Vercel 博客

Vercel 的 IP 地理定位现以更细的网络粒度解析访客位置：几乎所有请求可给出城市级数据，90% 流量可到邮编级；数据刷新更频繁，所有项目默认启用且无需改代码。
