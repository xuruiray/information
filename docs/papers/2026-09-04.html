GPT-6 Astra 发布：OpenAI 下一代模型开始面向有限组织推出

OpenAI 今日发布 GPT-6 Astra，首先向有限组织推出，并将在未来数日逐步向所有 ChatGPT Plus、Pro、Business 与 Enterprise 用户开放，同时接入 OpenAI API 和 AWS。该模型 API 定价与 Claude 保持一致。评论者指出这是向更广泛可用性过渡的起点，但尚未提供个人实测体验。
