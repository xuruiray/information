commit-rewriter 0.1：为发布整理提交信息的轻量 Web 工具 Simon Willison

Simon Willison 发布 commit-rewriter 0.1，这款小工具用于编辑 Datasette 安全发布版本的提交信息。原始提交中夹杂了大量编码智能体生成的杂乱内容和私有仓库的 issue 编号，不适合公开发布，用户可运行该工具修改仓库的提交信息。
