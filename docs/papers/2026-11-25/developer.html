基础设施与数据：Vercel Sandbox 镜像与 PrivateLink 端点更新

Vercel Sandbox 所有运行时改用 Vercel Managed Images；node22 等旧运行时使用 vercel/sandbox 开源镜像并经 Vercel Container Registry 分发，新建沙箱提供 64 GB 存储。Secure Compute 的企业团队可在 Vercel 仪表板创建和管理 AWS PrivateLink 端点；端点位于团队专用 VPC，使用该网络的 AWS 区域，并由连接的项目环境共享。Workflow SDK 允许按需删除已完成运行的存储数据，包括输入、输出、钩子负载和错误轨迹，以满足合规与安全要求。
