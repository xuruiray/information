将可执行文件与 SQLite 数据库合二为一：ELF 技巧 Simon Willison

Farid Zakaria 描述了一种巧妙的 Linux 模式：创建可直接作为可执行文件运行的 SQLite 数据库文件。技巧是将 SQLite 文件格式中的 4 字节应用 ID 设置为 SELF，代表结构化可执行与可链接格式（ELF），从而让数据库文件同时充当可执行程序。
