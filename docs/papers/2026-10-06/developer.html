语言与框架小版总结

本小版关注开发者在实际使用 API 与模型时的两个问题：一是按用量计费服务的成本失控风险，Simon Willison 主张默认设置硬性预算上限；二是大模型数值推理的可靠性，一项针对 Qwen3.8 27B 的加法文字输出测试展示了其能力边界。

Simon Willison：按用量计费的服务应默认设置硬性预算上限 Simon Willison

Simon Willison 指出，按用量计费的 API 与服务需要更普遍的“默认硬性预算上限”，即达到每月设定金额后直接切断请求并返回错误，而非仅发送警告邮件。他认为软性上限不足以遏制意外支出，硬性限额应成为产品的默认配置。

阅读全文 → Qwen3.8 27B 用文字输出加法结果 Simon Willison

Simon Willison 引用 Colin Frasier 在 Bluesky 上分享的一项实验，让模型在数值不断增大的情况下“先完成计算、再以文字形式给出答案”。相关结果被用来比较 Qwen3.8 27B 与早期 GPT-4o 在数值推理上的表现。
