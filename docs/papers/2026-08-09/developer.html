开发与编程版总结

本期开发与编程版聚焦 AI 编程工具与云开发平台的快速演化。Claude Code 将自动模式设为默认，AI 代理正成为标准工作流；开发者用同一游戏设定对比 Codex 与 GPT-5.6 的生成能力，一窥模型差异。安全方面，OpenAI 误攻 Hugging Face 的时间线浮出水面，Datasette 也发布 SQL 注入修复。Vercel 推出多项工具更新，从技能包、沙箱隔离到审计日志集成，持续完善云上开发体验。

语言与框架

6 条
语言与框架小版总结

本周该小版以开发平台工具更新为主：Hermes Agent 接入 Vercel AI Gateway 与沙箱，让代理在隔离环境中运行；skills.sh 推出技能包，方便团队共享代理技能；Herdr 支持每个编码代理使用独立 Sandbox；审计日志则新增 Datadog 等分析目的地。虽无核心语言版本发布，但这些工具链升级直接影响日常开发与安全运维。

Hermes Agent 现已支持 Vercel AI Gateway 与 Sandbox Vercel 博客

Hermes Agent 现在可以将 Vercel AI Gateway 作为推理层，并在隔离的 Vercel Sandbox 微虚拟机中运行代理命令。开发者可通过 AI Gateway 免加价访问 200 多个模型，所有请求会与其余用量和费用一起显示在 AI Gateway 仪表盘中。

阅读全文 → Vercel 审计日志新增 Datadog、Splunk 与 Panther 支持 Vercel 博客

Vercel 的 Audit Log Drains 现在可将团队活动日志流式传输到 Datadog、Splunk 和 Panther，加上已有的自定义 HTTPS 端点和 Amazon S3 目标。该功能面向 Enterprise 计划用户，可在 Drains 页面创建，适用于安全审计与事件追踪。

阅读全文 → skills.sh 推出技能包，可打包分享代理技能 Vercel 博客

开发者现在可以将多个代理技能打包为可分享的技能包，发布在 skills.sh 上。技能包可来自社区技能、本地文件夹和压缩包、公开或私有 GitHub 仓库；每个包都有独立未公开链接，方便单人使用或团队标准化技能配置，并支持一键安装。

阅读全文 → Herdr 中的每个代理均可使用独立 Vercel Sandbox Vercel 博客

Herdr 作为 tmux 风格的管理器，可在并排面板中运行 Claude Code、Codex、OpenCode 等终端编码代理。新插件让每个代理在各自的隔离 Vercel Sandbox 中运行，代理执行或编辑的任何操作都不会影响本机文件，项目文件会在启动时上传到新沙箱。

Datasette 1.0a38 发布，修复 SQL 注入漏洞 Simon Willison
