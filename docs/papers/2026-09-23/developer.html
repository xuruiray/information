开发与编程总结

本期开发与编程版面聚焦前沿模型发布后的开发者工具跟进。Anthropic 发布 Claude Opus 5.5，OpenAI 随后推出 GPT-6 Sol 与 GPT-6 Luna，价格约为上一代同级模型的一半。围绕这些新模型，命令行工具生态同步更新：llm-anthropic 0.29 加入 Claude Opus 5.5 支持，llm 0.36 注册两款 OpenAI 新模型并允许插件声明仅支持单轮对话的模型；llm-typesafe 0.1a0 则接入 TypeSafe AI 的 Jev 模型。此外，旧金山将于 10 月 14 日举办面向编码智能体开发者的交流活动。

开源与工具：LLM 命令行更新

LLM 命令行工具发布 0.36 版本，新增对 OpenAI GPT-6 Sol 与 GPT-6 Luna 的支持，模型插件还可声明某模型不支持多轮对话，LLM 在收到助手或工具历史时会报错，llm chat 也会在会话开始前拒绝此类模型。

llm 0.36 发布，支持 GPT-6 Sol 与 GPT-6 Luna Simon Willison

llm 0.36 新增 gpt-6-sol 与 gpt-6-luna 两个 OpenAI 模型；模型插件现可声明 supports_conversation = False，当仅支持单轮提示的模型收到助手或工具历史时，LLM 抛出 ConversationNotSupported，llm chat 也会在会话开始前拒绝该模型。
