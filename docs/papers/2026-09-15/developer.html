开源与工具总结

本小版聚焦三款开发工具的更新：Simon Willison 发布提交信息编辑工具 commit-rewriter 0.1；Vercel 的 AI SDK harness 层支持通过原生订阅完成认证；shot-scraper 1.12 新增 WebP 截图与质量参数。三者均为面向日常开发流程的小幅增量更新，而非平台级变更。

commit-rewriter 0.1 发布：在发布前整理提交信息 Simon Willison

Simon Willison 发布小工具 commit-rewriter 0.1，用于编辑提交信息。他最初为 Datasette 安全版本撰写该工具，因为早期提交中充满编码代理留下的痕迹和私有仓库的 issue 编号，不适合公开发布。

阅读全文 → AI SDK harness 层支持通过原生订阅认证 Vercel 博客

Vercel 更新 AI SDK 的 harness 层，在底层工具支持的情况下可通过原生订阅完成认证。该层以统一的 HarnessAgent 接口运行不同编码代理，开发者无需改动应用代码即可切换代理，也无需新增设置。

阅读全文 → shot-scraper 1.12 新增 WebP 截图支持 Simon Willison

Simon Willison 的截图自动化工具 shot-scraper 发布 1.12 版，新增 WebP 格式支持。用户可通过 -o screenshot.webp 输出 WebP 截图，并用 --quality 指定质量；不指定该参数时，WebP 文件为无损格式。
