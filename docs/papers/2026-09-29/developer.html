Claude Sonnet 5.5 上线 Vercel AI Gateway Vercel 博客

Vercel 宣布 Anthropic 的 Claude Sonnet 5.5 已在 AI Gateway 上线，模型标识为 anthropic/claude-sonnet-5.5。该模型适合范围明确的日常工作，涵盖功能开发、修复缺陷以及创建文档、幻灯片和电子表格。在编码任务中，它能多步推进修改并在报告完成前自查。

阅读全文 → Vercel 支持无需认证搜索域名 Vercel 博客

Vercel 现在允许用户无需登录或提供访问令牌即可发现域名并检查可用性与价格。该功能通过 Vercel CLI 和 Domains Registrar API 提供。使用 CLI 可按关键词或域名片段搜索；使用 Registrar API 可在单次请求中检查最多 200 个精确域名，并返回可用状态。

阅读全文 → Vercel Sandbox 新增内存可观测性 Vercel 博客

Vercel Sandbox 的可观测性现已包含内存使用数据。用户可以在仪表板中查看沙箱内存用量，也可以通过 CLI 的 vercel metrics 命令获取。仪表板新增的 Memory Usage 卡片报告沙箱的平均、P75 和 P95 内存使用量，与现有的 CPU 使用率和数据传输指标并列展示。
