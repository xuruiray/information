阅读全文 → 腾讯发布 Hy4 预览版：770B 参数开源大模型 Simon Willison

腾讯今日推出 Hy4 预览版，这是一个新的开源权重文本输入模型（无视觉），拥有 770B 总参数、49B 激活参数、100万 token 上下文窗口，模型权重约 1.56TB。与 7 月的 Hy3 相比，规模大幅提升，凸显国产开源大模型的快速迭代。

基础设施与数据总结

基础设施与数据板块聚焦 AI 基础设施：Vercel 支持 Claude 托管代理与 Chat SDK；安全研究者对 Claude Code 自动模式提出质疑；腾讯 Hy4 预览版现可在 AI Gateway 调用。

Vercel 发布 Claude 托管代理与 Chat SDK 集成 Vercel 博客

Vercel 宣布可在 Chat SDK 中运行 Claude 托管代理。该代理在服务端处理模型、工具、会话状态和沙箱化网络研究，开发者可据此构建类似 Slack 研究机器人的应用，每个线程拥有持久会话并流式输出带来源的简报。

阅读全文 → 研究者破解 Claude Code Opus 5 自动模式，提示注入防护遭质疑 Simon Willison

Anthropic 对 Claude Code 自动模式寄予厚望，将其设为默认以防御提示注入攻击，并宣称效果强大。但知名提示注入研究者 Johann Rehberger 公开了绕过方法，打破了该模式的防护承诺，引发对 AI 编码安全性的重新担忧。

阅读全文 → Hy4 预览版现已上线 AI Gateway Vercel 博客

腾讯 Hy4 预览版现已接入 Vercel AI Gateway。该开源 MoE 模型拥有 770B 总参数、每 token 激活 49B 参数，支持 100 万 token 上下文，面向长程编码、文档分析、游戏开发和科学推理等场景。开发者只需设置模型为 tencent/hy4-preview 即可调用。
