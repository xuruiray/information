3 条
航天能源与机器人小结

本小版收录量子材料计算、激光等离子体天线和超冷量子态实验。科学家改进近藤效应计算，使真实材料预测更准确；激光天线可调谐发射无线电波，面向卫星雷达；超冷铯原子中首次观测到贝特弦。

著名量子效应终于可在真实材料中预测 ScienceDaily 技术

科学家开发出计算近藤效应的新方法。近藤效应是磁性原子嵌入金属时出现的奇特量子现象。新方法不再依赖简化模型，而是使用材料真实的原子和电子结构，使研究人员能以更高精度预测材料行为。

阅读全文 → 科学家造出类似光剑的激光天线，可发射无线电波 ScienceDaily 技术

科学家展示一种形似光剑的新型天线，利用激光产生可调谐等离子体束来发射无线电波。该技术有望让天线按需改变尺寸和方向，从而革新无线通信，并在卫星、雷达和太空探索中具有应用前景。

阅读全文 → 1931年的量子预测如今成为现实 ScienceDaily 技术

在物理学家汉斯·贝特预测近一个世纪后，科学家在超冷气体中创造并直接观测到被称为“贝特弦”的奇特量子态。研究人员将铯原子冷却至接近绝对零度，并囚禁在数千个一维细管中，使原子组在没有寻常机制的情况下结合。

科学研究小结

本小版关注聚变能路径、恒星死亡后行星形成、宇宙氢信号测绘和载人航天返回。普林斯顿团队提出先加热再增压的聚变方案；哈勃数据暗示白矮星周围可能存在新生行星；CHIME 验证遥远宇宙测绘方法；NASA Crew-12完成237天任务。

科学家或找到通往聚变能的捷径 ScienceDaily 科学

普林斯顿等离子体物理实验室提出一种可能大幅提高效率的聚变路径：先加热等离子体，再提高其密度。计算显示，未来反应堆有望以更少能量接近自持聚变，并规避使点火更困难的隐藏问题。

阅读全文 → 哈勃旧数据或揭示恒星死后形成的行星 ScienceDaily 科学

哈勃旧观测中的异常化学信号可能指向一颗在恒星死亡后形成的行星。天文学家在白矮星 HS 0209+0832 周围发现铌含量异常高，推测恒星抛出的部分物质可能重新聚集为气态巨行星。TESS 数据还暗示有一颗木星大小行星近距离环绕。

阅读全文 → 90亿年前信号或有助于解释暗能量 ScienceDaily 科学

加拿大射电望远镜仅凭自身观测探测到数十亿年前氢的微弱辉光，证明一种期待已久的遥远宇宙测绘方法可行。CHIME 可利用这一氢信号追踪物质在空间中的分布，并测量宇宙随时间的膨胀，为研究暗能量提供新工具。

阅读全文 → NASA 宇航员完成1亿英里太空飞行后溅落返回 ScienceDaily 科学

NASA 的 SpaceX Crew-12 宇航员在太空停留237天后返回地球，飞行超过1亿英里、完成逾3792圈轨道，并开展面向未来月球和火星任务的研究。任务还取得创纪录的太空行走成果，以及可能改变太空和地面医学的实验进展。
