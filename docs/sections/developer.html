开源与工具：Vercel 支出管理、MCP 反馈与图像工具

Vercel CLI 新增 vercel budgets 命令，用于查看当前支出、生效预算并设置或删除按需预算；Vercel MCP 新增 submit_feedback 工具，可用自然语言提交缺陷、使用摩擦和功能请求；Simon Willison 发布 Seam Cutter 和 Quick Study，分别用于滑移切口裁剪图片和用画布与模拟画笔快速绘制照片。

Vercel CLI 新增支出管理功能 Vercel 博客

Vercel CLI 新增 vercel budgets 命令，可查看当前支出和生效预算，并设置或删除按需预算；设置预算本身不会停止用量。

基础设施与数据：Agent 生产访问、构建缓存与托管密钥

Vercel 说明其 Agent 访问生产系统时的权限设计，指出“修复部署”等请求并不预先说明所需操作；部署摘要现在显示构建缓存大小及其与构建机器上限的距离；Vercel Connect 可为每个 Agent 或任务创建单独的受限 Stripe API 密钥。

Vercel Agent 如何安全访问生产环境 Vercel 博客

Vercel 介绍其 Agent 访问生产系统时的权限设计：请求如“修复部署”并不预先说明所需操作，宽泛授权可能影响无关资源，逐步审批又增加负担。

阅读全文 → Vercel 部署页面显示构建缓存大小 Vercel 博客

Vercel 部署摘要现在显示每次部署节省的构建缓存大小及其与构建机器上限的距离，CLI 的 vercel inspect 和 get-deployment REST API 也可查看。

阅读全文 → Vercel Connect 新增托管 Stripe API 密钥 Vercel 博客

Vercel Connect 可为每个 Agent 或任务创建单独的受限 Stripe API 密钥，创建连接器时选择托管密钥，权限由用户设定，原有 MCP 与自带密钥方式不变。
